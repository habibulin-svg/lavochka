# Вечером на лавочке

Сборник дворовых игр в браузере. Лаунчер — вечерний двор 90-х, у каждой игры есть боты с уровнями сложности,
сетевая игра по коду комнаты и правила с наглядным показом на настоящем поле.

Сейчас готов **Шиш-беш**, остальные игры в каталоге отмечены «скоро» или «в планах» и появятся волнами.

## Запуск для разработки

Нужен Node.js 20+.

```bash
npm install
npm run dev          # сайт: http://localhost:5173
npm run dev:server   # сервер комнат: http://localhost:8787 (нужен только для режима «через сервер»)
```

## Проверки

```bash
npm run check        # типы + тесты (обязательно перед коммитом)
npm test             # только тесты
SIM_GAMES=40 npm test  # длинный прогон: по 40 партий ботов на каждое число игроков
```

Тесты (`tests/`) без браузера гоняют каждую зарегистрированную игру: боты доигрывают партии на любом
числе игроков и во всех пресетах, каждый шаг показа правил допустим, комната переживает обрыв и возврат игрока.

## Сборка и свой сервер

```bash
npm run build        # dist/ — статический сайт, dist-server/ — сервер
npm start            # раздаёт dist/ и держит комнаты на :8787 (порт — переменная PORT)
```

Без сервера сайт из `dist/` можно выложить на любой статический хостинг: локальная игра и P2P работают и так.

## Сетевая игра

- **Напрямую (P2P)** — по умолчанию. Комнату держит браузер хозяина стола, связь — WebRTC через PeerJS. Код комнаты — 5 знаков.
- **Через сервер** — партию ведёт сервер, чужие карты и роли не видит никто. Код — 6 знаков. Включается в «Настройках».

Код комнаты по длине сам подсказывает, куда подключаться. Если кто-то отключился, за него ходит бот;
вернуться можно по тому же коду (после перезагрузки вкладки сайт сам предложит вернуться).

### Деплой сервера

- **Render.com** (бесплатно, без карты): New → Blueprint → этот репозиторий, всё описано в `render.yaml` в корне репозитория.
  Бесплатный сервер засыпает после 15 минут простоя, первое подключение ждёт до минуты. Рекорды хранятся в файле
  и на бесплатном тарифе сбрасываются при перезапуске.
- **Любой VPS**: `npm ci && npm run build && PORT=80 npm start` (или за nginx). Рекорды — в `data/` (переменная `DATA_DIR`).

## Устройство

| Папка | Что там |
|---|---|
| `src/core/` | ядро: типы игр, комната (`room.ts`), авторитетное состояние (`authority.ts`), клиент, стол, лобби, правила с показом, настройки |
| `src/core/net/` | транспорты: PeerJS (`p2p.ts`) и WebSocket (`ws.ts`) |
| `src/cards/` | колоды: модель и отрисовка в трёх стилях; `stage.ts` — общая сцена карточных игр (полёт и переворот карт, вертикальная раскладка для телефона) |
| `src/launcher/` | двор-лаунчер |
| `src/games/catalog.ts` | каталог всех игр сборника |
| `src/games/<игра>/` | игра: `def.ts` (правила, боты, показ — без DOM), `view.ts` (отрисовка) |
| `server/` | сервер Node: комнаты, раздача сайта, рекорды |

**Как добавить игру.** Описать `GameDef` (setup / toAct / apply / view / result / bot / rules) и `GameView`
(mount / setView / play / setTurn), зарегистрировать в `catalog.ts` и `defs.ts`. Сеть, лобби, переподключение,
боты вместо отключившихся, журнал, чат и автосохранение достаются игре даром.

**Игры реального времени** (настольный хоккей): у `GameDef` есть `realtime` — `tick(state, inputs, rng)` 60 раз в секунду,
`input()` чистит ввод из сети, `bot()` даёт ввод бота каждый шаг. Ходов нет: комната (`room.ts`, на сервере, у хоста P2P
или в браузере) сама крутит шаги, клиент шлёт `input` (своё текущее управление), комната рассылает снимки `rt`
(в сеть — раз в `sendEvery` шагов, на локальный экран — каждый шаг). Вид получает их в `GameView.realtime()` и сглаживает
движение между снимками. Пока у кого-то грузится стол или людей нет — пауза.

Превью карточки снимается со страницы `/?thumb=<id>` (позиция из `def.showcase()`) и кладётся в `public/thumbs/`.

## Чужие материалы (все — CC0 или общественное достояние)

Настольный хоккей: фигурки `public/hockey/{red,blue}.webp` — сгенерированы пользователем по мотивам советской игрушки
(фон вырезан, ужаты в WebP); поле, борт, табло, надписи — процедурные, `src/games/hockey/tex.ts`.

3D-холдем (`src/games/holdem/*3d.ts`, грузится только в 3D-виде):

- **Люди за столом** — `public/models/holdem/*.glb`: Quaternius, «Ultimate Modular Men Pack» и «Ultimate Modular Women Pack»
  (quaternius.com, CC0). Ужаты: оставлены анимации Idle/Wave/Interact/HitRecieve, сжатие meshopt.
- **Мебель** — `public/models/room/*.glb`: Poly Haven (polyhaven.com, CC0) — television_02, vintage_cabinet_01,
  vintage_wooden_drawer_01, dining_chair_02, Rockingchair_01, wine_bottles_01; текстуры переведены в WebP 1K.
- **Фактуры** — `public/tex/holdem/`: Poly Haven (CC0) — herringbone_parquet, brown_leather, american_walnut_veneer,
  velour_velvet, fabric_pattern_05 (нормали), HDRI lythwood_room (отражения).
- **Ковёр на стене** — `public/tex/holdem/carpet_col.webp`: фото «Tovuz Kazak, Caucasus, late 19th century»,
  Wikimedia Commons, общественное достояние; белый фон вокруг краёв вырезан в прозрачность.
- **Потолок** — `ceiling_*.webp`: Poly Haven painted_plaster_wall (CC0).
- **Обои** — `wall_*.webp`: бумага — ambientCG Wallpaper001A (ambientcg.com, CC0: цвет, нормали, шероховатость),
  узор напечатан поверх своим скриптом (полосы с веточками, стыки полотен по 53 см).
- **Вид из окна** — `window_night.webp`: кусок ночной панорамы Poly Haven hansaplatz (CC0), перепроецирован в кадр.

Генератор видео-персонажей (картинка → видео через routerai.ru) — `tools/videogen/` (Python + tkinter, сборка в exe —
`build.bat`), промпты и требования к роликам — `docs/holdem-video.md` в корне репозитория.
