# Колода ханафуды

Готовит `tools/hanafuda/cards.py` из SVG с Викисклада: `<набор>/<id>.webp` (300×498, без бумажных полей), `back.webp` — рубашка.
id = месяц × 4 + место в месяце (`src/games/hanafuda/cards.ts`).

- `alt` — [традиционные цвета, чёрная рамка](https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_traditional_colors_(black_border)): Louie Mantia, すけじょ; рубашка — Spenĉjo.
- `alt2` — [традиционные цвета, красная рамка](https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_traditional_colors_(red_border)): Louie Mantia Jr., すけじょ; рубашка — Spenĉjo.
- `green` — [зелёные растения](https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_green_plants): Louie Mantia; рубашка — Louie Mantia, Spenĉjo.
