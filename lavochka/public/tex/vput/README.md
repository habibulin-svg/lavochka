# Поле «В путь-дорогу»

`city.webp` (город) и `park-*.webp` (парки по углам) — вырезки из фотографии поля из коробки «В путь-дорогу»
(издательство «Малыш», 1990, автор-художник Н. Обухова), присланной пользователем. Свет выровнен по белому листу,
фигурки на городе заделаны по второму снимку того же поля, фон парков выровнен. Дорожки, клетки, остановки и стрелки
рисуются в коде (`src/games/vput/view.ts`) по размерам с того же фото.
