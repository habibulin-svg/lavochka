# Поле «Разведчика и дозора»

`board.webp` — выпрямленный снимок поля из коробки «Разведчик и дозор» (издательство «Малыш», 1984, автор-художник Ю. Лобачёв).
Снимок прислал пользователь; поле выпрямлено по центрам кружков, сгиб посередине убран. Кружки и тропинки игры
(`src/games/razvedchik/engine.ts`, `PTS` и `EDGES`) размечены по этому снимку.
