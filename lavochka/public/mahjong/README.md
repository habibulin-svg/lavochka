# Рисунки костей маджонга

Готовит `tools/mahjong/tiles.mjs`. Файл `<вид>.svg`, вид — номер 0–41 (`src/games/mahjong/tiles.ts`); `4r/13r/22r` — красные пятёрки.

- `jp/0–33`, `jp/*r` — [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles), общественное достояние (CC0). `jp/31` (белый дракон) — своя рамка.
- `hk/*`, `jp/34–41` (цветы и сезоны) — Cangjie6, [Wikimedia Commons](https://commons.wikimedia.org/wiki/User:Cangjie6) (файлы `MJ*-.svg`), **CC BY-SA 4.0**. Изменение: снят нарисованный корпус кости, обрезано по лицу. Эти файлы распространяются на тех же условиях (CC BY-SA 4.0).
