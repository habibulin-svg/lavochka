# Поле «НЭП» — как собрано

Исходники (не в git, только для личного использования): фото оригинала `photo (1).jpg` (основное), `photo.jpg`, снимок с pikabu, PDF-новодел (значения патентов и тексты карточек), фото денег. Рабочая папка скриптов — `D:/temp/nep` (пути в скриптах).

1. `rect.py` — выпрямить центр с основного фото по углам внутреннего квадрата → `c1.png`; `align.py` (SIFT) — подогнать к нему второе фото и pikabu → `c0.png`, `c2.png`.
2. `center.py` — склейка: машина и человек — со второго фото (на основном там кубики и патент), под карточками — pikabu; сгибы затёрты → `center0.png`.
   `center2.py` — места под колоды «Шанс»/«Лотерея» нарисованы заново, логотип «НЭП» — чистым контуром по маске → `center.png`.
   `whiten.py` (после `center2.py`) — каёмка с подписями отраслей отбелена до цвета клеток (край с картинкой — прямой, буквы — чёрные; на поле не пропечаталась «Р» в «ресторане» — вставлена копия).
3. Всё поле выпрямлено с основного фото (`rect.py` по внешним углам → `full1.png`), `fullclean.py` затирает сгибы, `icons.py` / `cornericons.py` режут значки клеток и углов (фон — прозрачный).
   Заменены: кубик «Шанса» и звезда «Лотереи» на сгибе — соседними такими же; порты — одним кораблём; конь «Донской» (под фишкой) — силуэт со второго фото с заливкой; молния «Энергии» — узкой заплаткой по сгибу.
4. `render.py` — поле 2000×2000: зелёная рамка 34 px, угол 269, клетки набраны Arial Bold, полосы отраслей — градиентом, центр — `center.png` → `public/manager/nep.webp`.

Купюры 1–500 вырезаны с фото пачек (перспектива + баланс белого), рубашки карточек — белые с надписью Times, как на оригинале.
