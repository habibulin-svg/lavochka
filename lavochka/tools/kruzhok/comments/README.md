# Комментарии к классическим партиям кружка

Файл `<id>.json` на партию; `tools/kruzhok/games.ts` вливает его в `public/kruzhok/games/<id>.json`.
Справка для автора — `npx tsx tools/kruzhok/games-brief.ts` → `D:/temp/kruzhok/brief/<id>.txt`
(ходы с номерами полуходов `ply`, оценка Stockfish после каждого хода, пометки, остановки «А как сходил бы ты?»).

Формат:
```json
{
  "title": "Бессмертная партия",
  "intro": "2–4 предложения: кто, где, когда, чем партия знаменита.",
  "notes": { "36": "комментарий к полуходу 36 (19. К:h6+)", "...": "..." },
  "outro": "1–2 предложения: чем закончилось и чему учит."
}
```

Правила текста:
- Язык — простой русский, для кружка: от новичка до разрядника. Тепло, без канцелярита, без «мы видим».
  Голос — руководителя кружка (Михалыч), но без присказок в каждой фразе: одна-две на партию, не больше.
- **Комментарий к каждой остановке (★) обязателен**: его показывают сразу после ответа ученика, поэтому он
  объясняет идею хода (что под боем, что открылось, куда целит), не повторяя «правильно/неправильно».
- Комментарий к каждой ошибке (`?`, `??`): в чём ошибка, опираясь на «движок предлагал».
- Ещё 2–6 комментариев в поворотных местах (дебют — одна фраза о плане, перелом, решающий удар). Всего обычно 8–15.
- Каждый комментарий — 1–3 предложения, до ~45 слов.
- **Ходы — только из справки**, русской записью как в ней (Кр, Ф, Л, С, К, пешка без буквы, «:» — взятие).
  Не придумывай вариантов, которых нет в справке. Позицию сам не считай: опирайся на оценку и линии движка.
- Исторические факты — только общеизвестные и бесспорные (кто играл, турнир/матч, год, прозвище партии).
  Нет уверенности — не пиши. Не приписывай игрокам слов и мыслей. Оценки движка не пересказывай цифрами
  чаще, чем нужно: «у белых лишняя фигура», «перевес решающий», «мат неизбежен».
- Можно исправить `title`, если рабочее название неточно (короткое, по-русски; известное прозвище — лучше всего).
- Без разметки (звёздочек, списков) — обычный текст. Ключи `notes` — номера полуходов строкой.
