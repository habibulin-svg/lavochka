Ты составляешь таблицу ассоциаций для бота в командной словесной игре «Шифровка»: на поле 25 слов, капитан даёт ОДНО слово-подсказку, которое связывает несколько слов своей команды, а команда угадывает. Бот-капитан ищет подсказку, общую для нескольких слов поля; бот-отгадчик по подсказке ищет слова поля, у которых она есть в списке. Поэтому списки должны пересекаться через общие понятия.

Возьми слова из файла D:\Claude\Shish\lavochka\tools\shifrovka\chunks\CHUNK (по слову в строке). Для КАЖДОГО слова дай 25 ассоциаций — по убыванию силы (первые — самые очевидные, такие, что назовёт большинство людей). Требования:
- каждая ассоциация — одно русское слово строчными буквами (с ё, где она есть), без пробелов и дефисов; в основном существительные в именительном падеже, можно прилагательные (мужской род) и изредка глаголы (инфинитив);
- НЕ само слово и не однокоренные с ним (для «рыба» нельзя «рыбак», «рыбный»);
- для многозначных слов — ассоциации ко ВСЕМ значениям (ключ: замок, дверь, родник, скрипичный, гаечный...), сильнейшие значения первыми;
- обязательно включай категории и общие понятия (животное, птица, металл, кухня, спорт, музыка, инструмент, оружие, сказка, вода, дерево, космос, одежда, транспорт, цвет...) — через них слова поля связываются между собой;
- части и целое, место, действие, признак, цвет, известные выражения, персонажи;
- без мата, грубостей и политики; без повторов внутри списка.
Для топонимов (слова с заглавной буквы) — страна/материк, достопримечательности, язык, известные символы, еда, климат, «город», «столица», «река», «горы» и т. п.; ключ в JSON пиши с заглавной, как в файле.
