# Разметка озвучки «Заколдованной страны»

Фэнтези-книга-игра (советская настольная RPG 1990): ведущий читает рассказ вслух. Каждую строку озвучивают
нейросетью разными голосами: рассказчик + роли. Твоя задача — для каждой строки входа разбить текст на куски
«кто говорит» и подготовить текст для синтеза речи.

## Вход
`in-NN.jsonl` — по строке JSON: `k` (ключ), `src` (сцена), `text` (текст), иногда `prev` (предыдущая фраза сцены — для контекста).

## Выход
`out-NN.jsonl` (тот же номер) — по строке JSON на КАЖДУЮ строку входа, в том же порядке, ни одной не пропускать:
`{"k":"<ключ>","s":[["<голос>","<текст куска>"], ...]}`

## Голоса
- `nar` — рассказчик: всё повествование, слова автора («говорит он», «кричит стражник»), надписи, вопросы к игрокам.
- `villain` — злые маги, колдуны, Чёрный маг, некроманты, демоны-повелители: властный, зловещий.
- `sage` — добрые маги, волшебники, мудрецы, старцы-провидцы, жрецы, отшельники.
- `oldman` — старики, деды, старосты, нищие, сторожа в годах.
- `king` — короли, князья, правители, бароны, рыцари-вельможи, знатные господа.
- `soldier` — стражники, воины, командиры, наёмники, рыцари, гвардейцы, привратники.
- `rogue` — разбойники, воры, бандиты, торговцы-пройдохи, игроки в кости, хитрецы, корчмари-жулики.
- `commoner` — простые мужики: крестьяне, трактирщики, кузнецы, лодочники, гномы, горожане.
- `young` — юноши, парни, пленники-юнцы, оруженосцы, эльфы, подмастерья.
- `monster` — людоеды, тролли, великаны, орки, огры, драконы, рычащие чудовища.
- `imp` — мелкие существа: гоблины, бесы, клурки, кроны, карлики, крысолюды, шуты, болтливые зверьки.
- `ghost` — призраки, мертвецы, нежить, духи, голоса из темноты, говорящие черепа/статуи/двери.
- `girl` — девушки, принцессы, дочери, служанки, пленницы.
- `lady` — взрослые женщины: королевы, волшебницы, ведьмы-красавицы, хозяйки, феи.
- `crone` — старухи, бабки, старые ведьмы, гадалки.
- `child` — дети, малыши.

Если говорит сам отряд/игроки (что-то хором), или непонятно кто — `nar`. Один и тот же персонаж в сцене — один голос.

## Как делить
- Прямая речь в «ёлочках» — голосом персонажа, без кавычек; слова автора между кусками речи — `nar`.
  `«Я вас озолочу, — говорит он. — Для этого выпейте»` →
  `[["sage","Я вас озолочу."],["nar","говорит он."],["sage","Для этого выпейте."]]`
  (тире на стыках убрать, знак конца фразы поставить по смыслу).
- Надписи, названия, цитаты, песни, которые не произносит персонаж («На ярлыке написано: «ЯД»») — остаются у `nar`, кавычки убрать.
- Строка без чужой речи — один кусок `nar`.
- Соседние куски одного голоса склеивай.

## Текст для синтеза (меняй ТОЛЬКО это, остальное — слово в слово)
- Числа — словами в нужном падеже: «бросает 100 монет» → «бросает сто монет», «2 ОР» → «два очка риска», «на 18 уровне» → «на восемнадцатом уровне».
- Сокращения расшифровать: ОР — очки риска, КД — класс доспеха, ЖК — жизненная концентрация, ИО — игровые очки, БУ — бросок удачи, d6 — кубик. Слова КАПСОМ, которые не сокращения (ЯД, ДРАКОН), — писать обычными буквами (яд, дракон). РЭД — имя, оставить как «Рэд».
- `{name}` (имя героя) и `{leader}` (вожак) — заменить подходящим словом в нужном падеже: «герой», «вожак», «ваш товарищ»
  («Маг бросает {name} кошель» → «Маг бросает герою кошель»; «{name}, пить из бутылки?» → «Герой, пить из бутылки?»).
  `{n}` (выпавшее число) — убрать или заменить словом «столько» так, чтобы фраза звучала естественно.
- Значки ×, *, # и эмодзи — убрать (×2 → «два»).
- Буква ё — ставить, где она должна быть (ещё, всё ↔ все — по смыслу), остальное не трогать.

## Порядок работы
Прочитай свой `in-NN.jsonl` целиком, затем запиши `out-NN.jsonl` инструментом Write одним файлом (JSON в одну строку на
запись, UTF-8, без ```), затем перечитай и проверь: число строк выхода = числу строк входа, ключи совпадают, все голоса из списка.
В ответе — одной строкой: сколько строк размечено и сколько с ролями.
