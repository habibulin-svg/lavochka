# Задание: вопросы для кроссвордов и сканвордов

Ты пишешь вопросы (определения) к словам для русских газетных кроссвордов и сканвордов.

## Вход
Файл `in_NNN.tsv`, по строке на слово, поля через табуляцию:
`id  слово  вид  подсказка-смысла  известность`

- **вид** — «слово» (нарицательное) или вид имени собственного: «город», «река», «человек», «фильм», «персонаж», …
- **подсказка-смысла** — толкование из Викисловаря или описание из Викиданных. Это **только справка о значении**: не копируй её, пиши своими словами. Для людей там полное имя и кто это.
- **известность** — частотность (чем больше, тем ходовое слово) или `slN` — число статей в Википедиях.

## Выход
Файл `out_NNN.tsv` (тот же номер), по строке на **каждую** входную строку, поля через табуляцию, без заголовка:
`id  слово  годится  сложность  короткий  обычный`

- **годится** — `1` или `0`. Ставь `0`, если слово не годится для кроссворда:
  - это не существительное в именительном падеже единственного числа (местоимения «это», «она», частицы «нет», глаголы «есть»);
  - мат, грубое, оскорбительное, про национальности в уничижительном смысле;
  - аббревиатура («США», «СССР», «ЖКХ»);
  - слово малоизвестное, узкоспециальное, устаревшее без культурной ценности, или производное-однодневка («аборигенка», «антикритика», «аистёнок» — уменьшительные, женские формы профессий и национальностей, если они не самостоятельные слова);
  - для имён собственных: человек или объект мало кому известен в России.

  **Не бракуй** ходовые слова только за то, что они разговорные, устаревшие или книжные, если их знает обычный читатель газеты: «сельпо», «смотрины», «твердь», «финка», «термы», «рожон», «фраер», «ферт» — это хорошие кроссвордные слова. Уменьшительные бракуй, только если это просто форма другого слова («шарфик», «часик»), а не своё значение («родничок», «хоботок» — годятся).
  Если `0`, поля «короткий» и «обычный» можно оставить пустыми.
- **сложность** — `1` знают все (кот, Москва, Пушкин); `2` — общая эрудиция (аккордеон, Дунай, Гоген); `3` — трудное, для знатоков (анапест, Аквилон, Гильгамеш).
- **короткий** — вопрос для сканворда: **не длиннее 22 символов** с пробелами, 1–3 слова. Примеры: «Домашний мурлыка», «Река в Африке», «Автор «Онегина»», «Турецкий кинжал», «Сорт груши».
- **обычный** — вопрос для кроссворда: 3–12 слов, точный, в газетном стиле, можно с юмором или намёком. Примеры: «Самец домашней кошки», «Великая африканская река, текущая на север», «Поэт, «наше всё»», «Короткий изогнутый клинок янычар».

## Правила вопросов
- Ответ должен **однозначно** угадываться по вопросу и числу букв; вопрос должен подходить именно к этой форме слова (ед. число, им. падеж).
- **Нельзя** использовать в вопросе само слово, его корень и однокоренные («Кот — самец кошки» можно, а «Котёнок — детёныш кота» для слова «кот» нельзя).
- Для людей ответ — **фамилия**: «Автор «Мёртвых душ»» (Гоголь), «Композитор, «Лебединое озеро»» (Чайковский).
- Для фильмов, книг, опер, персонажей вопрос описывает произведение (автор, режиссёр, год, сюжет), не называя ответа: «Фильм Тарковского о Зоне» (Сталкер), «Опера Верди о египетской царевне» (Аида), «Мальчик из полена» (Буратино).
- Пиши грамотно, с буквой «ё», в кавычках-ёлочках «».
- Не придумывай фактов. Если не уверен, что за объект, ставь `0`.

## Как работать
Прочитай весь входной файл, напиши выходной файл целиком (инструментом записи файла), затем проверь: строк столько же, сколько во входе, в каждой ровно 6 полей, короткие вопросы не длиннее 22 символов. Ответь одной строкой: сколько строк, сколько с `годится=1`.
