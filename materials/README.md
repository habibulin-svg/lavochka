# Материалы для игр-ходилок (волна 7)

Только для личного использования, не публиковать.

## Большое космическое путешествие — `kosmos/kosmosput.jpg` (3131×2000)
Феликс Шапиро, художник Е. Милутка. Источник: https://printgames.ru/wp-content/uploads/2025/09/kosmosput.jpg
- 2–10 игроков, кубик d6, фишки-пуговицы. Старт — левая крайняя клетка нижнего ряда.
- Направление — по пунктирным стрелкам.
- Знаки: кружок — пропуск хода; квадрат — дополнительный ход; треугольник вверх/вниз — сдвиг на N рядов вверх/вниз;
  треугольник вперёд/назад — сдвиг на N делений; чёрный кружок — начать сначала. N написано на знаке.
- Побеждает тот, кто первым встретится с кометой (левый верхний угол).

## Кругосветное путешествие — `krug/krugput.jpg` (9928×6408)
Источник: https://printgames.ru/nastolnaya-igra-krugosvetnoe-puteshestvie/
- Любое число игроков, кубик d6. Старт и финиш — кружок «Москва»: побеждает первый вернувшийся в Москву.
- Знаки: вперёд, назад, бросить ещё раз, начать сначала. Разметку клеток снимать с карты.

## Колоды карт — `cards/<колода>/*.jpg`, `cards/back.webp`
Сканы 300 dpi из музея WWPCM (выбор пользователя 2026-10-10), из них `lavochka/tools/cards/build.py` собирает `lavochka/public/cards/`:
- Атласные — WWPCM04408/12 (с рамками, ок. 1965–2004): http://a.trionfi.eu/WWPCM/decks06/d04408/d04408.htm (файлы `016/d04408d16<масть><ранг>.jpg`)
- Славянские — WWPCM04409/04B (после 1980): http://a.trionfi.eu/WWPCM/decks06/d04409/d04409.htm (файлы `d04409<масть><ранг>.jpg`)
- «Русский стиль» — WWPCM04410/04 (после 1980): http://a.trionfi.eu/WWPCM/decks06/d04410/d04410.htm (файлы `002/d04410d02<масть><ранг>.jpg`)
- На каждую колоду — тузы, короли, дамы, валеты и по одной числовой карте масти (♠10, ♥9, ♦8, ♣7); остальные числовые 2–10 собираются скриптом из масти и шрифта.
- Рубашка — `cards/back.webp` (прислал пользователь, решётка), перекрашивается в три близких оттенка.
