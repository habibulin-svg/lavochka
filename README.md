# Шиш-беш — браузерная версия

Настольная игра на кресте для 2–4 игроков: боты трёх уровней, хот-сит за одним экраном и сетевая игра по коду комнаты.

## Запуск

Сборка не нужна — это статические файлы.

- **Проще всего:** откройте `index.html` двойным щелчком.
- **Надёжнее (рекомендуется):** запустите локальный сервер в папке проекта и откройте http://localhost:8765

```bash
python -m http.server 8765
```

Для сетевой игры и шрифтов нужен интернет: загружаются библиотека PeerJS (jsDelivr) и шрифты Google. Без интернета локальная игра и боты работают, только шрифты будут системными.

## Сетевая игра

1. Хост: «Новая игра» → у нужных мест выберите тип «Сеть» → «Начать». Появится код комнаты из 5 символов.
2. Друзья: «Присоединиться по сети» → имя и код.
3. Когда все подключились, хост нажимает «Начать игру» (или «Пустые места — ботам»).

Соединение прямое (WebRTC, P2P). Публичный сигнальный сервер PeerJS нужен только для установки связи. Всю логику и броски кубиков ведёт хост. Если игрок отключился, за него ходит бот, пока он не вернётся с тем же именем и кодом. Чтобы играть через интернет, выложите папку на любой статический хостинг (GitHub Pages, Netlify и т. п.) или просто пришлите друзьям файлы.

## Управление

- **Пробел** или кнопка «Бросить кости» — бросок.
- Подсвеченная фишка → цель. Если вариант один, фишка ходит сразу. Цели прыжков с углов показаны голубым: `↷1` — по прямой стрелке, `✕3` — по диагонали.
- ☰ — пауза и правила; 🔊 — звук; ползунок — скорость анимации.
- Локальная партия сохраняется автоматически: в меню появится кнопка «Продолжить игру».

## Правила в этой реализации

- **Поле как на классической доске:** плечо креста — 5 клеток, вместе с угловой клеткой креста выходит 6 клеток на сторону. Стартовое поле выступает за конец своей дорожки, справа на своём луче. Средняя дорожка луча — «песочные часы»: внешняя клетка лежит на круге, 4 внутренние — домик своего цвета.
- **Старт:** у каждого 4 фишки. Вывести фишку из парка можно только шестёркой, она встаёт на стартовое поле. Стартовое поле лежит вне круга, там фишку не срубить. Со старта шестёрка приводит ровно на угол креста. Второй кубик — ход любой фишкой.
- **Кубики** используются по одному, в любом порядке. Если сходить можно — ходить обязательно.
- **Лишний бросок:** дубль или срубленная фишка — игрок бросает ещё раз.
- **Круг:** ход против часовой стрелки, 12 клеток на четверть, 48 на круг. Затем фишка через торец своего луча заходит в домик.
- **Рубка и свои фишки:** фишка соперника рубится, если встать на её клетку. Две свои фишки на одной клетке стоять не могут.
- **Углы креста:** «1» — прыжок на соседний угол (прямо или вбок) или обычный шаг, «3» — прыжок по диагонали. Срезы разрешены.
- **Домики-укрытия** — 3-е поле с края каждой дорожки, друг напротив друга. В укрытии помещается одна фишка, выбить её нельзя. Если укрытие занято, пришедшая фишка встаёт на само поле, и там её можно срубить. Фишка в укрытии при этом заблокирована, пока поле не освободится.
- **Свой домик** — строго по очкам, без перепрыгивания своих фишек. Внутри домика фишки можно двигать дальше.

## Структура

| Файл | Назначение |
|---|---|
| `js/engine.js` | правила и состояние игры (без DOM) |
| `js/ai.js` | боты: лёгкий / средний / сложный |
| `js/board.js` | SVG-поле: процедурная текстура дерева, выжженные орнаменты, фишки, анимации |
| `js/dice.js` | 3D-кубики на CSS |
| `js/audio.js` | синтез звуков через Web Audio |
| `js/net.js` | P2P через PeerJS |
| `js/app.js` | экраны, сессии (локальная, хост, клиент), игровой стол |
