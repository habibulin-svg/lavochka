# Wordstat по играм — сводка с комментариями (2026-10-19)

Показы в месяц по Яндексу после чистки чужого контекста (`tools/seo/analyze.py`). **Играть** — головная фраза игрового намерения («X онлайн / играть / бесплатно»), **Правила** — головная фраза о правилах, **Скачать** — приложения (не наш трафик, но показатель интереса). Wordstat считает фразу вместе со всеми её продолжениями — цифры в строке не складываются. Подробно по играм — `analysis.md`, все фразы — `keywords.csv`, план страниц — `plan.md`.

## Выводы

1. Сильнее всего — пасьянсы, судоку, кроссворды, дурак, нарды, шашки: игры уже есть, нужны страницы под каждый крупный вариант.
2. **Маджонг** — лучшая новая игра по соотношению спрос/трудоёмкость.
3. Страницы правил — отдельный трафик: покер 56 тыс., нарды 26 тыс., бильярд и домино по 17–18 тыс., шахматы 17 тыс.
4. Наши эксклюзивы (советские настолки, Электроника, автоматы) в поиске почти не видны, но и соперников там нет — материал для соцсетей и сарафана.
5. Яндекс Игры — не приоритет: ссылки на сайт внутри игры запрещены (п. 8.4.2), реклама только их SDK, договор только с ИП/юрлицом, доход у небольших разработчиков — тысячи рублей в год (DTF, 2025). Если выкладывать — позже, одну-две узнаваемые игры ради бренда.
