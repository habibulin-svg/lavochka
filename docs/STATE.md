## Где мы сейчас

- **Волна 0 — готово.** Ядро сборника (`lavochka/`): лаунчер-двор, экран партии с вариантами правил, лобби, стол с журналом и чатом, правила с пошаговым показом, настройки, колоды (3 стиля, фигуры пока условные), сеть (локально / P2P PeerJS / сервер WebSocket), переподключение, бот вместо отключившегося, сервер с рекордами, деплой на Render.
- **Шиш-беш** перенесён на ядро; варианты (волна 1, п. 1) — готово: длинное поле, укрытия напротив / через один / без, выход на 6 / дубль / оба. Геометрия — `makeGeo(cfg)` в `engine.ts`, `cfg` лежит в состоянии партии.
- **Харнесс и хуки — готово.** `npm run check` (tsc + vitest), Stop-хук гоняет проверки, SessionStart подкладывает этот файл.

## Известные проблемы

- Render стоит за Cloudflare: из браузеров в РФ первая загрузка иногда очень медленная (38 КБ ≈ 11 с), бывает зависание до перезагрузки. Пользователь решил оставить как есть. Альтернативы: GitHub Pages для статики или российский VPS.
- Рекорды на бесплатном Render сбрасываются при перезапуске.

## Решения, принятые без пользователя

_(в автономном режиме записывать сюда всё, что решено самостоятельно)_

- Шиш-беш, «домики через один»: из 8 укрытий оставлено каждое второе по кругу — по одному на луч, на дорожке выхода хозяина луча (3-е поле от старта). Если имелось в виду другое — поменять `isHouseG` в `makeGeo`.
- Шиш-беш, длинное поле: домик — 5 клеток (вся средняя дорожка луча, кроме торца), фишек по-прежнему 4.
- Шиш-беш, «старт на дубль»: выводит любой кубик дубля; добавлен ещё вариант «на шестёрку или дубль» и «без укрытий».
