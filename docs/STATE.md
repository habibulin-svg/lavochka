## Известные проблемы

- Render стоит за Cloudflare: из браузеров в РФ первая загрузка иногда очень медленная (38 КБ ≈ 11 с), бывает зависание до перезагрузки. Пользователь решил оставить как есть. Альтернативы: GitHub Pages для статики или российский VPS.
- Рекорды на бесплатном Render сбрасываются при перезапуске.
- `tools/cards/build.py` использует шрифты Windows (`C:/Windows/Fonts`) — пересобирать колоды на этой машине.

## Решения, принятые без пользователя

_(в автономном режиме записывать сюда всё, что решено самостоятельно)_

- Шиш-беш, длинное поле: домик — 5 клеток (вся средняя дорожка луча, кроме торца), фишек по-прежнему 4.
- Нарды (пользователь): первым ходом с головы две шашки на **любой** дубль. Под местом для шашек ничего не выжигать — рисунок только медальоном в середине половины (пользователь, по фото досок).
- Нарды: кокс = марс + шашки проигравшего в первой четверти пути (в коротких — на баре или в доме победителя); «домашний марс» (4) не делал — источники противоречат.
- Гюльбара: первые три хода каждого игрока — без каскада; ограничения на голову нет (по умолчанию «сколько угодно»); остаток каскада — сопернику (по en.wikipedia).
- Нарды: при отказе от удвоения проигрыш по текущему кубу; Кроуфорд — автоматически в матче с кубом.
- Шиш-беш, «старт на дубль»: выводит любой кубик дубля; добавлен ещё вариант «на шестёрку или дубль».
- Шиш-беш, «домики через один» (уточнил пользователь по фото доски): укрытия лесенкой — на дорожке входа 3-е поле с края, на дорожке выхода 4-е.
- Нарды и шиш-беш (пользователь): выбор фишки только подсвечивает цели (в нардах светится всё «копьё» пункта), ход — нажатием на цель; при наведении — бледная подсказка. Настройка «ходить автоматически, если вариант один» осталась как была.
- Дурак, варианты (источники молчат или расходятся): «классический» = простой (без подкидывания); «длинный» = колода 52; «японский» = козырь всегда бубны + пики бьются только пиками; «г*вно» = серия со званиями (Король, Принц, Граф, Барон, Мужик, последний — Г*вно), король назначает козырь до раскрытия колоды, г*вно сдаёт, первым ходят под него; обмена картами нет. Погоны — последний ход против дурака одной-двумя шестёрками. Подкидывают по очереди: сначала ходивший, потом по кругу; кому нечем — пропускается сам. После взятия ходит следующий за взявшим. Ничья — если в последнем коне карты кончились у всех.
- Перевод показом козыря — каждым козырем раз за кон; перевод в первом коне разрешён.
- Дурак командами: если одна команда вышла целиком, оставшиеся — дураки, даже если кто-то из них вышел раньше (иначе им пришлось бы ходить друг под друга).
- Джокеров в колодах пока нет (`cardHTML` рисует простую картонку) — понадобятся для «101 с джокерами», скачать с тех же страниц WWPCM.
