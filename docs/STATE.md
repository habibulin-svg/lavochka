  - **Скорость** — `core/dvorsport/sim.ts`: `DS_SPEED_OPTION` (ключ `speed`, по умолчанию **1 «как в жизни»**; 0,8 и 0,6 — для новичков) и `dsSpeed(opts)` вместо аркадного `SPEED_OPTION`/`gameSpeed` (тот был 0,5 по умолчанию и вдвое замедлял всю физику). `BODY` — бег 6,8 м/с, рывок ×1,55 на 0,4 с (перезарядка 1,3 с), разгон 0,08 с, радиус тела 0,35 м. `drive(тело, {mx,my,dash}, vmax, dt)` — скорость к желаемой, разворот больше 90° гасит старую скорость (без «танка»); `dash(тело)` — начать рывок (true — начат). Тело — `{x, y, vx, vy, dash, cd}`.
  - **Расталкивание** — `separate(тела, r = BODY.r, fixed?)` после движения в каждом шаге (и в паузе/подаче): пары ближе 2r разводятся поровну (до 3 проходов), порядок фиксирован — детерминированно; `fixed(i)` — кого не двигать (бьющий у дома). Совпавших ровно в точке разводит по номерам.
  - **Замедление** — `slowmo(s, сек, k)` в движке на событии (удар, ловля с лёта, осалили), шаг движка `dt = TICK × s.speed × dtScale(s)`; в состоянии — `slowUntil`, `slowK`.
  - **Подсказки** — `core/dvorsport/coach.ts`: `new Coach(обёртка)`; `coach.say(html, ['Пробел'], hot)` — крупно внизу «что делать сейчас» со значками клавиш (на телефоне значков нет — там кнопки `Pad`); `coach.pop('+2', x, y, 'good'|'bad')` — всплывающая надпись над точкой (px холста из `yard.toScreen`); `coach.banner(большое, мелкое, мс)`; `coach.edge(yard.toScreen(мяч), w, h, 'мяч')` каждый кадр — стрелка у края экрана, когда мяч за кадром.
  - **Метки на земле** — `core/dvorsport/marks3d.ts`: `new GroundMarks(yard.scene)`; каждый кадр `marks.begin(dt)`, `marks.ring(id, x, y, цвет, r, {pulse, dashed})`, `marks.arrow(id, x0, y0, x1, y1, цвет, max)`, `marks.end()` (неназванное прячется). В лапте: свой — жёлтое дышащее кольцо, на кого переключит Tab — белое пунктирное, бегущие (в защите) — красные, куда упадёт мяч — оранжевое крутящееся, стрелка — куда бежать / к мячу / в кого кидать.
  - **Обучение** — `new Tutor(обёртка, 'игра', шаги)`; шаг `{ text, keys, done(), when?(), hold? }`: показывается первый несделанный шаг, который сейчас к месту (шаги можно сделать в любом порядке), `tutor.tick()` каждый кадр, `tutor.showing` — прятать `coach.say`, `tutor.holding` — слать во вводе `hold: true`: движок замирает (только если соперник — компьютер), двигается только свой пацан (`frozen` в `engine.ts` лапты). «Пропустить» и конец — `store ds.tutor.<игра> = done`; `Tutor.reset(игра)` — показать снова.
