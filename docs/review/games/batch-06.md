## skat
- **важно (не уверен)** `src/games/skat/engine.ts:419-420` — `schwarz = defTricks === 0 || s.tricks[d] === 0` передаётся в `gameValue` как признак шварца для ИГРОКА. Когда играющий не взял ни одной взятки (проигрыш), это тоже считается «шварцем» и повышает множитель проигрыша (`gameValue` добавляет `m++` при `outcome.schwarz`). Сценарий: играющий без взяток платит `-2 × (базовое × (матадоры+1+шварц))` — возможно, завышенный штраф. Проверить по правилам: множитель шварца при проигрыше играющего должен учитываться только если защита взяла 0 взяток и играющий выиграл бы в ином случае — не уверен.
- Очки и значения проверены: `BASE` (D 9, H 10, S 11, C 12, гранд 24), 61 из 120, шнайдер (90/30), скат в `finishHand` — совпадают с текстом `seo.ts` и `def.ts`.
- `redact`/`makeView` — чужие руки скрыты, скат видит только взявший, `put`/`orig` — только играющий (как и должно быть). Бот `skat/ai.ts:99` использует `v.put`, который у защиты пуст — утечки нет.

## morskaya
- **важно (не уверен)** `src/games/morskaya/def.ts:69` (`view: (s) => s`) + `engine.ts:127, 183` (событие `mine` с полем `at`, без `redact`) — положение мин открыто обоим игрокам. Сценарий: соперник видит, куда тральщик поставил мину, и обходит её. Если мины по замыслу скрытые (класс «минное поле»), нужен владелец мины в состоянии, `view` без чужих мин и `redact` для `mine` (скрыть `at` чужим местам).
- **важно (не уверен)** `src/games/morskaya/engine.ts:173-181` — мины без владельца: тральщик, снявший чужую мину (`s.mines.includes(sh.p)`), кладёт её в СВОЙ запас (`s.stock[seat]++`, стр. 180). Сценарий: тральщик встаёт на мину соперника (тральщики не подрываются) и пополняет свой запас, хотя по правилу «у каждого три мины» мина принадлежит тому, кто её ставил. Проверить правило «снимает мины на своём кружке»; возможная починка — учитывать владельца мины.
- Проверено: старшинство (`senior`), удар в корму (`hitAt`/`canHit`), подлодка без мин/пушек (`rollsAt`), пушки противника (`GUNS[1-side]`), счёт «на время» (`QUIET`) и текст `WHY` — совпадают. Ход «мина» не переключает очередь — по правилам «это не ход».
