## chizh
- **важно (не уверен)** `src/games/chizh/engine.ts:671` — автоловля: водящий ловит чижа без нажатия кнопки, если чиж в радиусе `CATCH.auto` (0.3) и на высоте 0.6–1.8: `(d < CATCH.auto && z > 0.6 && z < 1.8) || (btn && d < CATCH.reach)`. Сценарий: чиж пролетает рядом с водящим, который не нажимал кнопку, — поймано без действия игрока. Это ход, который делается за человека. Починка: засчитывать ловлю только по кнопке (`btn`), либо если помощь задумана — описать её в правилах и показе.

## solitaire
- **важно (не уверен)** `src/games/solitaire/def.ts:232` (`view`, поле `seed` в возврате, строка 242) — клиенту уходит `seed`. По нему `deckOf(game, c, seed)` (def.ts:162) восстанавливает всю колоду, включая закрытые карты и порядок талона. Скрытие в `deck` (`null` для неоткрытых) обходится. В дуэли это соперник-видимая информация о колоде. Сценарий: клиент вызывает `deckOf` с `seed` из view. Починка: не отдавать `seed` в view чужим местам; при дуэли — только свой `seed` или не отдавать вовсе.
