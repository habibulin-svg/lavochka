## borodino
- **важно** (не уверен) `src/games/borodino/engine.ts:639` — `ready` вызывает `fixDeploy(s, sd)`, который молча переставляет части вне зоны расстановки на ближайшие допустимые клетки. Сценарий: игрок оставил часть за пределами своей зоны и нажал «Готово» — часть переехала сама, без его хода. Починка: не давать нажать «Готово», пока все свои части стоят в зоне (`deployOk`), и не переставлять их автоматически.
- **мелочь** (не уверен) `src/games/borodino/def.ts:210` — `view: (s) => s` отдаёт всё состояние, включая расстановку русских, французу при его расстановке. Сценарий: если расстановка должна быть скрытой, второй игрок/бот видит позиции первого. Починка: решить, нужна ли тайна расстановки; если да — в `view` скрывать чужие части до фазы боя. Бот `ai.ts` сейчас на расстановке только жмёт «Готово», так что утечки через бота нет.
(Бой, ЗОС, таблица CRT и движение не читались построчно.)

## cah
- **важно** (не уверен) `src/games/cah/engine.ts:365` — `if (bet) s.subs[s.subs.length - 2].bet = true;` ставит метку ставки не на ставочный ответ, а на основной. После `push` ставки индекс `length - 2` — это основной ответ, а ставочный уже помечен на строке 364. Сценарий: игрок с очком положил ставку — на открытом раунде основной ответ подписан как «на залог». Игровая логика (`settle`) завязана на `seat`, поэтому очки не страдают, но отображение врёт. Починка: удалить строку 365 (метка уже стоит на ставочном ответе), либо если задумано — пометить явно.
- **мелочь** `src/games/cah/engine.ts:462` — флаг `blanks` в `makeView` считается по руками всех мест (`s.seats.some((x) => s.hands[x].some(isBlank))`), поэтому каждый игрок видит, что у кого-то из соперников есть пустая карта. Сценарий: индикатор «в игре пустые карты» раскрывает чужие руки. Починка: считать только по колоде/сбросу и по своей руке (`sees`).
(Бот `ai.ts` смотрит только в `v.hands[seat]` — ок.)

## petteia
- **важно** `src/games/petteia/engine.ts:271` — в Шедлере (`noSuicide: true`) прыжки (`jumpsFrom`) не проверяются на запрет «встать между двумя чужими без взятия» (в отличие от шагов, строка 266 через `suicide`). Цепочка прыжков (`chainJumps`, `apply`/`step`) тоже без проверки. Сценарий: фишка прыгает через соседа и встаёт между двумя вражескими фишками без взятия — ход разрешён, хотя по правилу (`engine.ts:36-37`, `rules.noSuicide`) запрещён. Починка: в `legal` для прыжков и в `step` для цепочки применять ту же проверку `between && !captures`, что и для шагов.
(Расстановка Шедлера тоже не проверяет `between` — стоит уточнить правило и при необходимости добавить (не уверен).)

## Проверка (Sonnet)
- puzzles, football, danetki, quoridor, tafl, mancala, abalone: замечаний не было.
- borodino: `ready` → `fixDeploy` переставляет части — ложная тревога: все ходы расстановки проходят `deployOk`, `fixDeploy` лишь подчищает начальные позиции вне зоны; кнопка «Готово» не ломает ход игрока.

- cah: метка `bet` на основном ответе (engine.ts:365) — ложная тревога/спорно: помечены оба набора как «залог игрока», очки считаются по месту, отображение лишь косметика; не трогал.
- cah: флаг `blanks` в `makeView` смотрел чужие руки — подтверждено, исправлено (cah/engine.ts, `sees(x)`; в UI не используется).
- partizany: комментарий про разведчика — подтверждено, исправлено (partizany/engine.ts).
- petteia: Шедлер, прыжки и цепочки без запрета «между двумя чужими без взятия» — подтверждено, исправлено (petteia/engine.ts: `badStop`/`jumpViable`, учтены `legal`, цепочка, `hasMove`; тест в tests/petteia.test.ts). Расстановка Шедлера — спорно: правила расстановки не уточнены, не трогал.
- hearts: Омнибус, стрелок луны с валетом бубен получает −10 вместо 0 — спорно: у стрелка JD-бонус по оригиналу может сохраняться; текст правил «себе 0» про валета не говорит. Спросить пользователя.
