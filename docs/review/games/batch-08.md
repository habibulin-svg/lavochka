# Пачка 08

## akcii
- **важно** `src/games/akcii/engine.ts:761` — суд: при втором разе в суде игрок выбывает по условию `shadow > 0 && courts > 0`, без проверки карточки фининспектора. Сценарий: игрок один раз прошёл суд (теневик с инспектором), снова стал теневиком без карточки инспектора и встал на «Суд» — выбывает. Правила (`def.ts`, раздел «Теневая экономика и суд»): «Теневику без карточки инспектора суд не страшен», выбывает «попавшись теневиком второй раз» — то есть с обеими карточками. Починка: проверять `s.shadow[seat] > 0 && s.inspector[seat] && s.courts[seat] > 0` перед выбыванием.
- **важно** `src/games/akcii/engine.ts:1395` — `view(s)` возвращает состояние целиком (identity). Клиенту уходят `shadow` и `inspector` всех игроков (скрытая роль, виден только собственный значок в `view.ts:478-479`) и остаток колоды `deck`. Сценарий: чужой теневик и наличие карточки инспектора видны через состояние стола/сеть (не уверен, что по правилам это скрыто, но интерфейс рассчитывает именно на скрытие). Починка: `view(s, seats)` обнуляет `shadow`/`inspector` чужих мест, колоду отдаёт длинами.
- **мелочь** `src/games/akcii/bot.ts:1-6` — комментарий обещает «Бот видит то же, что и человек: скрытого нет»; после правки `view` (см. выше) это станет верным, пока — бот получает полный state.

## lapta
- **мелочь** `src/games/lapta/engine.ts:318` — `swap()` сбрасывает `s.auto = [true, true]` для обеих команд: после смены подач управляемый человеком пацан на время переходит на ИИ, пока человек снова не выберет (не уверен, возможно, так задумано). Починка: сохранять `auto` для команды, которой человек управлял, либо пояснить в правилах.

## magiya
- **мелочь** `src/games/magiya/view.ts:320-330` — `glide()` запускает `setTimeout(finish)` и цепочку `requestAnimationFrame(tick)`; `destroy()` (`view.ts:478`) их не отменяет. Сценарий: выход со стола во время анимации фишки — колбэк ещё несколько сотен миллисекунд трогает отсоединённый элемент. Не падает, но не освобождается. Починка: хранить id таймера и кадра, отменять в `destroy`.
- **мелочь** `src/games/magiya/engine.ts:327-329` — предел кругов: побеждает только `best[0]`, ничья по `score()` не ловится (при полном равенстве очков побеждает первый в порядке мест). Редко (`score` включает дроби по треугольникам). Починка: при равенстве верхних очков — несколько победителей, как в `endTurn` для `finish`.
