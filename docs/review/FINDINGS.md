# Найденное при ревью — сводка

Статусы: **исправлено** (коммит), **открыто** (нужно решение пользователя или крупная работа), **принято** (так задумано).

## 1. Требования CLAUDE.md (`tests/requirements.test.ts`)

- FAQ не 4–5 вопросов: chess 3, checkers 2, ur 6, domino 2, mahjong4 3, yahtzee 3, loto 2, perudo 3, durak 3,
  solitaire 2, elektronika 3, brick 3, avtomaty 3 — **исправлено** (дописаны вопросы, у ur убран шестой).
- beglye: нет `seo.ts`, нет показа правил — **исправлено** (три показа). Заодно в движке **исправлено**:
  «заблудился в лесу» не отнимал ход; из монастыря выходили на любой грани, хотя правила (и текст страницы) говорят
  «только с „Побегом“ или „Юрьевым днём“»; «Побег» не давал обещанного лишнего броска; после гибели — снова в
  монастырь. **Решение без пользователя:** движок приведён к тексту правил, а не наоборот.
- beglye: знаки «лошадь», «лошадь с телегой», «лодка» есть на 19 пунктах карты, но ни на одной грани кубика
  (`FACES` в engine.ts) — поэтому никогда не срабатывают, хотя правила о них пишут. **Открыто**: нужно свериться с
  оригиналом (какие знаки на гранях, или эти пункты действуют без кубика).
- Аркады без пошагового показа правил (hockey, football, aerohockey, basketball, zarulem, treasures, shariki,
  brick2026, eggs) — **принято**, записаны в `KNOWN` теста.
- Карточки-разделы (`members`) и отложенные «Петарды» (`shelved`) тест пропускает.

## 4. Сложные игры (слой 3) — спорное и крупное, нужен ответ пользователя

Исправленное — в отчётах `deep/<игра>.md` и коммитах «Ревью: …». Открыто:

- **detektiv: файл с ответами (`data/key.ts`, 590 КБ) лежит в клиентском бандле** — разгадку можно прочитать из кода
  страницы. Через `view` не утекает. Починка крупная: ключ только на сервере, а P2P-хост держит движок сам.
- geroi: зритель и запись карты видят мир целиком (туман — только на клиенте); нет версии сохранений и миграций;
  чат без лимита; `join` по коду обходит ранний доступ.
- gops: места и хозяин комнаты привязаны к имени; любой участник может прислать неверный хеш (рассинхрон).
- poker: короткий ва-банк не закрывает торговлю для уже ходивших; принос в стаде; лишние фишки — по местам, а не
  от баттона.
- thousand: тёмная выше 120 считается с поднятой суммы ×2; бочка у сдающего вчетвером; bridge: «все спасовали» в
  Чикаго/спортивном.
- preferans: пуля сдающего вчетвером на распасах (в «Ростове» пишет, в остальных нет).
- manager: «день рождения» — платят, сколько есть (упрощено, без заклада); банк платит кредитору за банкрота;
  monopol: ничья даёт winners=[]; рынок и вложения.
- durak: бот длинного дурака не учитывает вышедшие карты.
- secret-hitler: `rebalance` на 6 игроков без снятия карты из колоды; mafia: у мёртвых нет режима зрителя.
- kruzhok: облачный журнал «новее побеждает целиком» (прогресс с двух устройств теряется); таймер загрузки Stockfish.
- nardy: шаги «на сумму костей» после выбора уходят подряд сами; shishbesh: прыжки с угла назад; chaupar: закончивший
  в паре ждёт союзника.
- korona/detektiv: «Уже читал» одного сбрасывает дело у сидящих на нём.
