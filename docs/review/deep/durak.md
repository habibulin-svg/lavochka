# Глубокое ревью: Дурак (src/games/durak/)

## Находки
1. engine.ts:828 (finishGame), важно: погоны выдавались и тогда, когда дураком остался сам ходивший. Сценарий: колода пуста, Вовка ходит шестёркой, Ленка кроет последней картой и выходит; Вовка (остался с картами) получал погон за собственную шестёрку, хотя правило — «дурака добили шестёркой». Исправлено: погон только если дурак — отбивающийся последнего кона (`s.defender === fool`). Тест: tests/durak.test.ts, «погоны».
2. engine.ts:439 / 82 (deckSize, cfgFrom), мелко: `hand` до 12 при 6 игроках не влезает даже в 52 карты (раздача даст неравные руки, а при пустой колоде и без козыря возможен undefined). В интерфейсе опции `hand` нет, достижимо только подделкой правил по сети. Не трогал (спорно: проверка параметров — зона core).
3. def.ts:90 redact, пометка: ветка `if (ev.type === 'pass') return ev;` лишняя, но безвредна. Не трогал.
4. Спорно: ai.ts `unseen` для длинного дурака не учитывает выложенные (laid) карты и шестёрки — только оценка шансов, ход всегда допустим. Не трогал.
