# «Викторина» — устройство (решения 2026-11-08)

Запрос пользователя: одна карточка, форматы внутри — тривиа (4 варианта, уровни сложности, одному и по сети на скорость), «Миллионер», «Поле чудес» (слово по буквам), «Сто к одному», «Своя игра», ещё что-то подобное; **режим кнопки как buzzin.live с поправкой на задержку (latency correction)**; база — тысячи вопросов, пишут субагенты на Haiku.

`id: viktorina`, адрес `/viktorina/`, раздел — компания (`cat: 'company'`), игроков 1–8, `added: '2026-11-08'`.

## Кнопка и часы (ядро уже сделано, коммит 6eb4586c)
`src/core/clocksync.ts`, `GameDef.clock` (`types.ts`, описание `ClockDef`), комната `room.ts` (`stamp`, `scheduleWake`), клиент отвечает на ping с часами, харнесс с виртуальными часами.
- Клиент при нажатии шлёт действие с `at: eventTime(e)` (момент события клавиши/пальца, `clocksync.eventTime`). Комната переводит `at` в свои часы (не позже прихода, не раньше чем позволяет погрешность связи), дописывает `now` (приход) и `win` (окно ожидания по самому медленному игроку).
- Движок решает «кто первый» не по приходу, а по `at`, и только после `min(at) + win`: ставит `wake(s) = firstAt + win`, по будильнику (`{type:'wake'}` от места −1, пропустить в `free`) объявляет победителя кнопки.
- Боты времени не знают: `bot.choose` возвращает «реакцию» (`{type:'buzz', rt: мс}`), движок считает `at = openedAt + rt`. Сила бота — быстрота и точность. Нажатия ботов «из будущего» (at > now) честно участвуют: окно закрывается только когда `now ≥ min(at) + win`.
- Фальстарт: нажатие до открытия кнопки (вопрос дочитывается) — блок на 0,5–1 с (как в buzzin/«Своей игре»).
- Показывать на экране: кто нажал, с поправкой «на 37 мс раньше» (разница скорректированных времён) — это и есть фишка режима.
- Таймеры вопросов (время на ответ, на нажатие) — тоже будильником комнаты, не клиентом: тогда бот и отключившийся не подвешивают партию.
- Часы на экране: `roomToLocal(t)` для обратного отсчёта.

## Режимы
- **Тривиа:** N вопросов (10/20/30), темы (все или выбранные), сложность (лёгкие 1–2 / средние 2–4 / трудные 4–5 / нарастающая). Одному — время на вопрос по желанию, очки за верный и быстроту, рекорд. Компанией — **на скорость**: все отвечают одновременно, очки: верно = 100 + бонус за скорость по скорректированному времени (`at − openedAt`), первому верному +50.
- **Кнопка:** вопрос (без вариантов) показывается, кнопка открывается; кто первый — отвечает: выбор из 4 вариантов (по умолчанию) или ввод с клавиатуры (настройка); неверно — минус очки, кнопка снова открыта для остальных; время на ответ после нажатия 7 с.
- **Лестница:** один игрок (или компания по очереди — каждый своя лестница), 15 вопросов нарастающей трудности (по `d`: 1,1,1,2,2, 2,3,3,3,4, 4,4,5,5,5), суммы 100…1 000 000, несгораемые 1 000 и 32 000, подсказки 50:50 / помощь зала (гистограмма, точность зависит от `d`) / звонок другу (совет с уверенностью), «забрать деньги». Время по желанию.
- **Барабан:** 1–3 игрока по кругу (боты добирают до 3), слово из банка `word` с подсказкой. **Барабан крутит сам игрок** (жест или кнопка), выпадает: очки (100…1000), ×2, «Б» банкрот, «П» приз — открыть любую букву, «+» — открыть букву по выбору, «0» — ход переходит. Назвал букву: есть — очки × количество, ход продолжается; нет — ход переходит. Можно назвать слово целиком (неверно — выбывает из тура). 3 тура + финал (по желанию — короче: 1 тур).
- **Сто опрошенных:** вопрос из банка `poll`, 6 ответов на табло, игроки называют ответ **вводом с клавиатуры** (сверка: нормализация, ё→е, синонимы `alt`, расстояние Левенштейна ≤ 1–2 по длине, основа слова без окончания). Раунд «простая игра»: по очереди называют, 3 промаха — ход команде соперника «отыграться». Очки — числа ответа ×1/×2/×3 по раундам; «обратная игра» (найти самый редкий) — по желанию. Одному — набрать как можно больше за 3 промаха.
- **Табло тем:** 5–6 тем × 5 цен (100…500) из банка `board`, раунды (2-й с удвоением). Выбирает ячейку последний ответивший верно; ответ — по **кнопке** (часы, как выше); ответ вводом (сверка как в опросе) или выбором из 4 (варианты достраиваются из других ответов той же темы/банка — настройка). Одному — все ячейки отвечает сам.
- **Верю — не верю:** утверждение из `mc` (вопрос + вариант: 50 % верный, 50 % ложный), ответ «верю / не верю», на скорость компанией.

## База

Скрипт сборки (`studio/jobs/viktorina/build_bank.py`): проверка формата, дубли (нормализованный текст вопроса/слова), отсев по длине, выкидывание помеченных проверкой фактов → банк игры в `lavochka/src/games/viktorina/bank/` (несколько JSON по форматам), грузится отдельным куском (не в основной бандл), как словари `hangman`/`balda`. ## Бот
3 уровня: вероятность верного ответа от `d` и уровня (лёгкий 0.75→0.25 по d, средний 0.9→0.45, сложный 0.97→0.7), время реакции на кнопку (лёгкий 1.6–3 с, средний 1–2 с, сложный 0.6–1.3 с), опрос — выбирает из 6 ответов с весом по числу (сложный — чаще верхние), барабан — частотные буквы русского языка + открытые позиции, называет слово, когда открыто ≥ 60–80 %.
