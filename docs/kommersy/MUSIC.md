# Коммерсы: музыка по эпохам

Зачем: проигрыватель по эпохам игры. Музыка меняется по году пути Коляна (1988–2003) и по ситуации (дорога, сделка, падение, клуб, финал). Песни с вокалом, в духе русской поп-музыки своих лет. Тексты полностью оригинальные, шуточные («любовная чушь, восстание машин и прочее»).

Генерирует YuE2 (`studio/runners/yue2.py`). Задание: `studio/jobs/kommersy/06-music.yaml` (16 треков, сиды 11 и 22, до 150 с, вокал включён).

## Как запускать

```
G:/ai/venvs/3d/Scripts/python.exe studio/runners/yue2.py studio/jobs/kommersy/06-music.yaml
```

Результат: `G:/temp/studio/out/kommersy/06-music/<имя>-<сид>.flac` (плюс `.abc` и `manifest.json`).

## Лицензия

Как в докстринге `studio/runners/yue2.py`: веса CC BY-NC 4.0 + разрешение YuE2 (2026-09-16) «индивидуальным авторам» монетизировать результаты; пользователь самозанятый, действует как физлицо (решение 2026-11-01). Адаптер Mothersuperior «instrumental» не используем.

## В игре

Проба (y88-1, y93-1) прошла — по-русски YuE2 поёт разборчиво (пользователь: «справляется прекрасно»), набор сгенерирован целиком.
Упаковка: `sh studio/post/music_kommersy.sh` — громкость −16 LUFS, затухание последних 4 с, ogg q3 → `lavochka/public/kommersy/a/music/<имя>-<сид>.ogg`.
Проигрыватель — `lavochka/src/games/kommersy/music.ts`: эпоха по году пути, оба варианта каждой песни по кругу вперемешку, кнопка ♪ на сцене (запоминается).
