## 3. Студия: как устроен конвейер ассетов

```
задание YAML (пишет make_jobs.py) → run.py → ComfyUI → out/<игра>/<партия>/ + manifest.json → post/sheet.py → sheet.jpg
```

- Задания не пишутся руками по одному: **`studio/jobs/<игра>/make_jobs.py`** держит списки (темы × время суток × слои, оружие × иконка/в мире, ролики) и генерирует YAML. Правка — в списке, перезапуск — готовое не пересчитывается (манифест).
- **Очереди** — bash-скрипты `studio/pipeline_<игра>*.sh`: картинки и видео — по очереди на 4070, вырезка/спрайты — на 5060 (`CUDA_VISIBLE_DEVICES=1`). Следующая очередь ждёт строку «конвейер N закончен» в логе предыдущей. Логи — `G:/temp/studio/pipeline-*.log`. Ошибка партии не роняет очередь (`|| step "ОШИБКА"`).
- **Переделка брака** — отдельная партия с суффиксом (`22b-arsenal-fix`, `24c-fix-keys` → `25c-fix-videos`, `24d`/`25d`) и своя очередь; в игре — таблица замен (`CUTSCENE_FIX` в `assets.ts`).
- В манифесте у каждого файла — промпт, сид, граф и **лицензия модели**.
- Постобработка (`studio/post/`): `sheet.py`/`video_sheet.py` (листы выбора), `seamless.py` (бесшовный грунт **резкой по шву наименьшей разницы**), `video_sprites.py` (ролик → кадры → вырезка BiRefNet или ключ по яркости `--key luma` для эффектов на чёрном), `atlas.py` (атлас + JSON), `terrain.py` + `export_levels.py` (маски уровней), `finish_music.py`, `jingles.py`, `asr_score.py`, `cutscenes.py`, `pack_<игра>.py` (WebP/Opus/MP4 → `public/<игра>/a/`).
- Превью уровней снимает **сама игра**: `/gops.html?shot=<id>` + `node tools/thumbs/gops-levels.mjs` (Chrome по протоколу отладки).

Партии ГОПС для ориентира по объёмам: 20-brand 48, 21-themes 520, 22-arsenal 166, 23-common 66, 24-cutscene-keys 52, 25-videos 52, 26-sfx-arsenal 140, 29-actors 14, 30-liquids 12, 32-voices 540 × 2 дубля, 41-cutscene-sfx 102.

## 4. Подводные камни (на что наступили)

**Установка и окружение**
- Hugging Face из РФ отдаёт файлы по-разному: Stable Audio — только через VPN, ACE-Step/Chatterbox — напрямую; XL-sft докачан с ModelScope (HF обрывался).
- `uv` тянет PyTorch по IPv6 — у пользователя не работает; колёса качать `curl -4` и ставить из локальных.
- llama.cpp под CUDA 12 тормозит на RTX 50xx — нужна сборка CUDA 13. PATH в Windows рос до предела (исправлено в «Переезде»).
- Временное — только на `G:/temp` (диска D нет), Chrome без окна — с `TEMP=G:/temp`.

**Картинки и 3D**
- Z-Image рисует латиницу чисто, **кириллицу — абракадаброй**: русские надписи — только кодом/шрифтом поверх (логотип студии латиницей, «ГОПС» на титуле — шрифтом).
- TripoSG по виду спереди «досочиняет» длинный козырёк — эталон давать в ¾.
- Бесшовность смесью со сдвинутой копией **двоит предметы в грунте** — только резка по шву.
- Иконки «тёмное на тёмном» и логотипы брендов (энергетик) — брак, переделка светлыми и без логотипа (`22b`).

**Видео (Wan 2.2)**
- Надписи в кадре (бочка «Квас») — абракадабра; в промпте явно «без надписей».
- Эффекты (большой взрыв, всплеск, пыль, кирпичи) часто тянут в кадр полосу воды/земли; всплеск не удался дважды (корона; капли стоят + водопад сзади) — **простые эффекты сразу рисовать кодом**, Wan — только для огня/дыма/взрыва на чёрном.
- Бойцы в роликах — по тексту, а не наша 3D-модель: похожи, но не один в один. Если нужно точное сходство — ключевой кадр рендерить из Blender, Wan только оживляет.
- Кадры роликов 960 px — на весь экран мыло; апскейл Real-ESRGAN до 1920 обязателен.

**Звук и музыка**
- YuE2 упирается в `max_duration` и обрывает трек на громком месте — ставить длину с запасом, обрывы гасить затуханием 3 с (`finish_music.py`).
- Chatterbox: ударений нет, ruaccent меняет «е» на «ё» и под transformers 5 требует `token_type_ids`; итог — заменён Qwen3-TTS.
- Все звуки — нормализация по классам громкости и длины, иначе взрыв тише шага.

**Код**
- Детерминизм: в `sim/` только целые (Q8), таблицы sin, свой rng, фиксированный порядок обхода; тест `sim-rules.test.ts` ловит `Math.sin`/`random`/`Date`. Маски уровней считаются в Python заранее и грузятся готовыми — расхождение `Math.sin` между браузерами исключено.
- Кадры прицела в атласе Blender идут **снизу вверх** — рука шла против мишени (`960 − aim`). Порядок кадров атласа проверять глазами на листе.
- Генератор ставил старт/финиш под воду (r13 непроходим) — тест высадки на **всех** уровнях (`tests/gops/levels.test.ts`).
- Мир должен шагать и в фоновой вкладке (таймер, а не только `requestAnimationFrame`) — иначе сеть рассыпается.
- Сообщение WebSocket ≤ 64 КБ — снимок мира слать частями.
- **Pixi 8: `Application.destroy()` портит общий на страницу пул пакетов:** второе живое приложение и каждое следующее падает на первом кадре (карта под боем в «Героях»). Приложения не уничтожать, а отдавать повторно (`src/geroi/render/pixi.ts`). ГОПС всё ещё уничтожает своё; там приложение на странице одно за раз, но повторный бой стоит проверить.
- Z-Image: описание города в промпте детали («стена в стиле такого-то города») рисует целый городок с крестами. Для кусков — только материал и одна деталь.

**Выкладка**
- Git LFS: **сначала** `git-lfs` на сервере, потом LFS-файлы в `main` — иначе выкладка подтянет указатели вместо картинок. `.gitattributes` — только папка ассетов новой игры.
- `vite build` берёт ~1,5 ГБ кучи: на VPS с 2 ГБ сборку убил OOM, сайт лёг. Теперь своп + `systemd-run --scope MemoryMax` + откат `dist/`; тариф 4 ГБ.

## 7. Локальные LLM 27B/35B — почему не вышло и куда встроить в следующей игре

**Что было.** План (`PRODUCTION.md` §0, `CODE.md` §0): Claude пишет архитектуру и тесты-спецификации, локальная модель через OpenCode пишет черновые модули по заданиям `studio/code-tasks/*.md`. Настроено: `~/.config/opencode/opencode.json` — `local/qwen9b` (:8081, 5060) и `local27/qwen27b` (:8080, обе карты). Замеры после переезда: llm-code (27B) 22 ток/с, llm-moe (35B-A3B) 37 ток/с, vlm 48 ток/с.

**Почему не вышло.**
1. **Ресурс.** 27B Q4 (16,5 ГБ) занимает **обе** карты (`-ts 12,8`), 35B-A3B — 4070 + 18–20 ГБ RAM. А 4070 двое суток без перерыва гоняла ComfyUI (5 очередей картинок и Wan), 5060 — вырезку, SFX, TTS. Окна для «режима код» не нашлось ни разу.
2. **Скорость против Claude.** Пока локальная модель ждала окна, Claude писал ядро сам (пользователь: «пиши ядро и движок сам») — к моменту, когда карта освободилась бы, задания уже были сделаны.
3. **9B не тянет.** На 5060 параллельно с ComfyUI жила только 9B: `rng` — да, маска — почти, `fx` (фиксированная точка, таблицы) — нет. Задания уровня «модуль с тестами» ей не по силам.
4. Задания писались под код ядра — то есть на **критическом пути**. Всё на критическом пути Claude делает быстрее, чем локальная модель с ревью.

**Как встроить в следующую игру (решить ДО старта контента).**

| Где | Что отдать | Почему подходит |
|---|---|---|
| **Окно «код» в расписании GPU** | В план очередей (`pipeline_*.sh`) явно вписать окна: например, днём 4070+5060 — 27B (`mode.ps1 code`), ночью — ComfyUI. Очередь контента сама останавливает/поднимает серверы | Без явного окна модель не запустится никогда — это главный урок |
| **35B-A3B параллельно с ComfyUI** | Проверить в первый день: 35B-A3B с `--n-cpu-moe` на **5060 + RAM**, 4070 остаётся ComfyUI (Wan с block swap тоже ест RAM — замерить, хватит ли 32 ГБ) | Если влезает — локальная LLM работает круглосуточно рядом с картинками |
| **Не критический путь** | массовые тексты (реплики, погоняла, описания, советы, брифинги по готовой таблице уровней), промпты партий по спискам `make_jobs.py`, раскладка звуков роликов, переводы, `names.ts`/SEO-черновики | Ошибка дешёвая, проверка — глазами/тестом формата; сейчас это агенты Sonnet/Haiku, т.е. лимит облака |
| **VLM-отбор (27B со зрением)** | первый проход по `sheet.jpg`: «годно/брак + причина» в JSON (`studio/qa.py`, ещё не написан), Claude смотрит только спорное | Отбор ~1000 картинок глазами Claude — дорого по контексту |
| **Код — только листья** | модули без зависимостей с готовым тестом: таблицы данных (оружие, юниты), парсеры, генераторы имён, перенос Python-генератора в TS со сверкой выхода, стили/вёрстка меню | Не на критическом пути; провал = Claude делает сам позже, ничего не теряется |
| **Пробный день** | Перед новой игрой прогнать `studio/code-tasks/gops-01-fx-rng.md` на 27B и 35B: проходит/нет, время, сколько правок. Записать сюда | Решение «давать код или нет» — по замеру, а не по надежде |

Правило: **задание локальной модели не должно быть на пути, по которому Claude идёт в ту же неделю.** Ставим ей то, что иначе ушло бы агенту Sonnet или вовсе не делалось.

## 8. Чек-лист новой крупной игры

1. `docs/<игра>/DESIGN.md` → пользователь отвечает на открытые вопросы.
2. Концепты стиля → выбор пользователя → `studio/bible/<герой>.md`.
3. Герой → 3D (эталон в ¾) → Blender → атлас; проверить порядок кадров.
4. Музыка: референсы пользователя → проба YuE2 → полный прогон (`max_duration` с запасом) → `finish_music.py`.
5. `jobs/<игра>/make_jobs.py` + `pipeline_<игра>*.sh` **с окнами для локальной LLM** (§7); 35B-A3B параллельно — проверено.
6. Агенты: уровни, тексты, реплики (или локальная LLM).
7. Код по §5, ассеты прямо с выхода конвейера.
8. Отбор (мой) → переделки отдельными партиями → простые эффекты кодом.
9. Озвучка Qwen3-TTS + `asr_score.py`.
10. Обвязка §6 целиком: пауза, ♪, ?, сохранения, заставка студии, ролики **со звуком** и апскейлом, проигрыватель музыки по ситуациям, всё сгенерированное в деле.
11. LFS: сервер → `.gitattributes` → `pack_<игра>.py` → тест ассетов.
12. Сайт: карточка `page:`, `/<slug>/`, SEO, новость, превью, `EARLY`.
13. `npm run check` → пуш → проверка прода.
