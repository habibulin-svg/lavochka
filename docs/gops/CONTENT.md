## 0. Каким будет продукт (решение пользователя 2026-11-01)

ГОПС — **не как остальные игры сборника** (карточка → настройка → стол «слева поле, справа меню»). Это **полноэкранная игра**:

1. **Заставка:** логотип **Lavochka Games** (короткий ролик: двор, загорается фонарь, садятся голуби, на лавку падает кепка → логотип) → титульный экран ГОПС (ключ-арт, музыка меню).
2. **Главное меню** поверх живого фона (двор в сумерках, лавка). Режимы — из `DESIGN.md` §2.
3. **Кампания:** карта города (иллюстрация с районами) → миссия: экран загрузки (картинка + совет) → бой → итог со звёздами → **межигровой ролик** (как в Worms: 5 секунд, смешно, без сюжета — «война районов» и всё).
4. **ПК и телефоны:** горизонтальная ориентация; на телефоне — крупные кнопки, жесты (тап — прыжок/выстрел, удержание — сила, перетаскивание — камера, щипок — масштаб), меню оружия — сеткой иконок на весь экран. Ролики — mp4/webm с пропуском по тапу.
5. В сборнике — одна карточка, открывающая игру на весь экран; сеть и голос стола — тем же `core/` (решим при коде).

## 3. Принятые без пользователя решения (поправимые)

- **Темы уровней — 12:** двор, гаражи, стройка, свалка, завод, рынок, депо, дачи, зима, теплотрасса, школа, пляж на Оби. У каждой своя смертельная жидкость (лужа, мазут, цемент, кислотная жижа, кипяток, прорубь, Обь…) и 2–3 времени суток → ~30 разных «картинок» боя на 45 миссий.
- **Названия оружия** — закрыл все **[?]** из `DESIGN.md` §3.1: управляемый воздушный змей, ледобур (бур вниз), кукурузник-химик (напалм), посылка с минами (минный удар), бабкин самогон (святая граната), стадо коз, чугунная ванна, прорыв трубы (вода поднимается), кирпичный град, маршрутка (телепорт), огнетушитель-ранец, «Буратино» (низкая гравитация), кеды, лазерная указка, невидимка, энергетик (двойной урон), заморозка, пулемёт вместо «шайтан-трубы». Итого 50 позиций (со «курю/сдаться/ты иди»).
- **Ящики:** оружие — на парашюте из полосатого зонта, аптечка — на воздушных шариках, утилиты — на простыне.
- **Ролики — Wan 2.2 TI2V-5B (Apache-2.0), 1280×704, 5 с, без речи** (как в Worms — пантомима и звуки). Проба: 49 кадров 704² — 77 с; полный ролик ~8–12 мин. Бойцы в роликах — по тексту, не наша 3D-модель: похожи, но не один в один (кепка, треники, расцветки). Если важно точное сходство — следующий шаг: ключевые кадры рендерить из Blender нашей моделью, а Wan только оживляет.
- **Анимации снарядов-«персонажей»** (собака, бабка, козы…) — тоже через Wan «на месте» → кадры → вырезка. Оружие в руках — отдельным спрайтом поверх позы прицела (как в Worms), поэтому у гопника позы рук по углам, а не 50 анимаций с каждым оружием.
- **Взрывы и эффекты** — ролики на чёрном фоне → прозрачность по яркости → спрайт-листы.
- **Логотип Lavochka Games** — латиницей (Z-Image рисует латиницу чисто); название «ГОПС» на титуле — шрифтом в коде (кириллицу диффузия рисует плохо).
- **Озвучка — Chatterbox Multilingual (MIT):** веса скачаны напрямую (`G:/ai/models/tts/chatterbox`, VPN не понадобился), в venv `tts` поставлен torch 2.7.1 cu128 из локальных колёс. Голос — официальный русский мужской образец из демо Chatterbox (`studio/voices/ru_m.flac`, подсказка пользователя), характер шести наборов — сдвигом высоты/темпа и `exaggeration` (`PITCH` в `studio/runners/tts.py`). Свой образец набора — `studio/voices/<набор>.wav`, перебивает общий. Ударений нет (пакета `russian_text_stresser` нет в PyPI) — если где-то ударение не туда, ставить в тексте вручную или переписать фразу. Партия `32-voices`: 540 фраз × 2 дубля на 5060.
- **Отбор вариантов — мой** (решение пользователя 2026-11-01: «Весь отбор поручаю тебе»).
