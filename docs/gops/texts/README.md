# ГОПС — игровые тексты (черновик для правки)

Все файлы — UTF-8 JSON, проверены на валидность. Тон: дворовой юмор 90-х, без мата, оскорблений и крови. Тексты — черновые, пользователь правит.

| Файл | Что | Объём |
|---|---|---|
| `voices.json` | реплики для озвучки: 6 голосовых наборов (`sipliy`, `intelligent`, `maloy`, `batya`, `sibiryak`, `botan`), у каждого `описание_голоса` для TTS и 30 ситуаций × 3 варианта; ключи ситуаций расшифрованы в `_ключи_ситуаций` | 540 фраз |
| `names.json` | погоняла бойцов по умолчанию | 120 |
| `brigades.json` | 6 бригад: девиз, характер, спецоружие (`is_new: true` — новое, например «Якорь на цепи» у Затона), открытие через N ходов, фразы выбора | 6 бригад, 12 фраз |
| `weapons.json` | по каждому id из `WEAPONS` (`studio/jobs/gops/make_jobs.py`): название, описание для меню арсенала, подсказка управления | 50 оружий |
| `ui.json` | меню, режимы (12), пауза, настройки, 10+10 заголовков победы/поражения, звёзды, 11 рангов, 40 советов загрузки, названия 19 роликов (18 скетчей + `logo-anim`), 15 событий диктора по 3 варианта | см. ниже |

## Объёмы
- Фразы бойцов: 540 (6 × 30 × 3).
- Диктор: 15 событий, 45 реплик.
- Советы: 40. Ранги: 11. Заголовки победы и поражения: по 10. Погоняла: 120.
- Оружие: 50 описаний + 1 новое (Якорь на цепи) в `brigades.json`.
- Всего порядка 900 строк текста.

## Как использовать
- Озвучка: из `voices.json` брать `описание_голоса` как промпт тембра для TTS (Chatterbox/CosyVoice), фразы — по ключу ситуации; файлы называть `<набор>/<ситуация>_<номер>.opus`.
- Игра: `names.json` — выдача погонял при создании бригады; `weapons.json` и `ui.json` — подгружаются в меню; `brigades.json` — экран выбора бригады.
- Названия оружия совпадают с `WEAPONS` в `make_jobs.py`; если там что-то переименуют, обновить `weapons.json`.
- Ролики: ключи `подписи_роликов` — id из `SKETCHES`.
- Открытые вопросы (спецоружие районов, сюжет) помечены в `docs/gops/DESIGN.md` §9; `brigades.json` предлагает вариант.

Ничего не закоммичено.
