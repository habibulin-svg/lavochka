## 1. Где лежит

`lavochka/src/gops/` — отдельное полноэкранное приложение в репозитории сборника (общие сервер, `core/audio`, комнаты и голос — потом).

```
src/gops/
  sim/            детерминированная логика: БЕЗ DOM, БЕЗ float в состоянии, БЕЗ Math.random/Date
    fx.ts         фиксированная точка Q8, целочисленные sin/cos/atan2/isqrt
    rng.ts        mulberry32 (тот же, что в studio/post/terrain.py)
    mask.ts       битмап ландшафта: твёрдо/воздух, вырезать/добавить круг, лучи, нормаль, связность
    terrain/      генератор ландшафта по рецепту уровня (перенос studio/post/terrain.py)
    world.ts      состояние мира и шаг step(world, input)
    body.ts       физика тел (точка/круг против маски), отскок, покой
    worm.ts       боец: ходьба по склону, прыжок, сальто, падение, урон от падения, прицел
    weapons/      оружие: таблица + поведение снарядов
    turn.ts       ход: ящики → ход (таймер) → отход → ждём покоя → урон/выбывшие → следующая бригада
    input.ts      ввод одного кадра (лок-степ по сети)
    hash.ts       хеш мира (сверка клиентов)
  bot/            боты: перебор выстрелов на копии мира тем же sim
  render/         PixiJS v8: ландшафт (текстура темы × маска), камера, спрайты из атласов, эффекты, жидкость
  ui/             DOM поверх холста: HUD, сетка оружия, меню, экраны, ролики
  data/           таблицы оружия, загрузка missions.json и текстов
  net/            лок-степ поверх core/realtime (этап 3)
  main.ts         вход приложения
```

Тесты — `lavochka/tests/gops/*.test.ts`.

## 2. Правила sim (детерминизм)

Один и тот же сид + один и тот же поток ввода → бит в бит один и тот же мир на любом браузере. Отсюда:

- **Числа в состоянии — только целые.** Координаты и скорости — Q8 (1/256 пикселя) в обычных `number`, все операции заканчиваются `| 0` или `Math.trunc`/`>>`. Деление — через `fdiv` из `fx.ts` (усечение к нулю).
- **Никаких `Math.sin/cos/atan2/sqrt/pow/exp`** в sim — только таблицы и целочисленные функции `fx.ts`. Углы — в 1/4096 оборота (`ANG_FULL = 4096`).
- **Случайность — только `Rng` из `rng.ts`**, состояние rng — часть мира.
- **Порядок обхода фиксирован:** массивы, не `Map`/`Set` с порядком вставки от случайных событий; сортировки — стабильные по id.
- Шаг — фиксированный 60 Гц (`TICK_HZ`). Рендер интерполирует, sim не знает о времени кадра.
- sim отдаёт **события** кадра (взрыв, всплеск, звук, урон, выбыл) — рендер и звук берут эффекты оттуда, а положение тел — из состояния.
- Тест `tests/gops/sim-rules.test.ts` проверяет исходники sim на запрещённое (`Math.sin`, `Math.random`, `Date`, `performance`, `document`, `window`).

## 3. Масштабы

| Что | Значение |
|---|---|
| Карта | 1920 × 704 логических px (как `terrain.py`), маска `Uint8Array` W·H, 1 = земля |
| Боец | хитбокс-круг r = 9 px, рост спрайта ~48 px на экране |
| Гравитация | 0,15 px/кадр² (подбирается) |
| ХП | 100 по умолчанию (схема/миссия меняет) |
| Ход | 45 с, отход 3 с (схема) |

## 4. Порядок работ

1. **Фундамент sim:** `fx`, `rng`, `mask` (+ тесты) — черновик локальной модели, ревью.
2. **Ландшафт:** перенос `terrain.py` → `sim/terrain/` (сверка с масками Python по доле совпадения пикселей ≥ 99%).
3. **Тела и боец:** физика, ходьба, прыжки, вода; песочница в браузере с маской и квадратиком-бойцом.
4. **Рендер:** PixiJS, тема «двор» из отобранных ассетов, атлас бригады, камера, телефон.
5. **Оружие ядра (8):** «Муха», лимонка, обрез, «Макаров», рогатка, тротиловая шашка, мина, верёвка; ветер; ящики.
6. **Ход и партия:** turn-машина, боты 3 уровня, быстрый бой против бота.
7. Меню, кампания из `missions.json`, ролики; затем сеть (лок-степ) и hotseat.
