# Кампании «Заколдованной страны» — задание автору

Кампания — полноценное приключение поверх той же карты и тех же 15 замков книги: сюжет на **десятки часов** игры
(вместе с боями, замками и дорогами), который можно водить с друзьями (ведущий — человек) и играть одному (ведущий — бот).

## Прочитать сначала
1. `docs/analysis/zs-authoring.md` — памятка автора сцен (язык, тон, правила записи) — **всё оттуда действует**.
2. `lavochka/src/games/zakoldovannaya/script.ts` — язык сцен (Step, Scene, Site, PlanData, Cond…).
3. `lavochka/src/games/zakoldovannaya/content/campaigns.ts` — формат `Campaign` (intro, scenes, sites, places, layout,
   triggers, rooms, road, roadScenes).
4. `lavochka/src/games/zakoldovannaya/content/c1.ts` — образец сцен; `content/forpost.ts` — образец места-меню без плана.
5. `docs/analysis/zs-map.md` — карта: узлы, местность, замки и их узлы. `docs/analysis/zs-monsters.md` — опасности.
6. `docs/analysis/zakoldovannaya.md` — правила коротко. Книга ведущего — `materials/zakoldovannaya/txt/ZS_kniga_vedushego.txt`
   (замки книги можно и нужно использовать как места действия сюжета).

## Как устроено в движке
- Партия начинается с оформления героев, потом играет `intro` (пролог) — отряд стоит у Форпоста (узел 138), в Форпост можно
  войти (лавка, трактир, храм). Дальше отряд ходит по карте; на узлах — дорожные встречи (`road`: книжные «Прочее»,
  свои `roadScenes` с метками, или оба), в замках — сцены комнат.
- `triggers` — сюжетные события: `on: 'node'` (отряд пришёл в узел — путь останавливается), `'site'` (вошёл в место),
  `'room'` (вошёл в комнату места: `site` + `room`), `'day'` (наступил день ≥ day, проверяется утром), `'flag'` (флаг
  взведён — проверяется после каждой сцены). `if` — доп. условие. По умолчанию срабатывает один раз.
- `rooms: { 'c3:7': 'princess' }` — подменить сцену комнаты замка книги своей сценой (ключевые для сюжета комнаты).
- `sites` + `places` — свои места на **белых** узлах карты (не на замках и не на 138). Без `plan` место — одна сцена-меню
  (как Форпост: `nodes` + `{ node: 'menu' }`, выход — `{ end: true, repeat: true }`); с `plan` (PlanData: `images: [null]`,
  `sizes: [[520, 330]]`, комнаты с x/y в этих единицах, связи, вход) — исследуется по комнатам, как замок
  (рисуется пергаментной схемой). У своего места `card: 0` (дом) или `card: -1` (лагерь/пещера — значок ⛺).
- `layout` — своя раскладка 15 замков по местам карты (порядок мест — как в zs-map.md, раздел «Замки», сверху вниз);
  без неё — книжная.
- Ключ сцены кампании — `'camp:<id кампании>:<id сцены>'`, поле `id` сцены должно быть таким же.
- Конец: `{ finish: 'win', say: '…эпилог…' }` (и, если хочешь, `finish: 'lose'` на провал сюжета). Гибель всего отряда —
  поражение само.
- Дневник: `{ quest: 'id', text: '…' }` — записать задание, `{ quest: 'id', done: true }` — выполнено. Игроки видят дневник.
- Боты проходят кампанию сами (тесты!): у каждого ключевого `ask` должен быть вариант, который ведёт вперёд, с `bot: 2–3`;
  никаких тупиков, где сюжет встаёт навсегда (если нужен предмет — дайте второй путь). Подсказки «куда идти» — в тексте
  и дневнике (например: «Старик сказал, что Гном живёт в Железном замке, к западу за рекой»).

## Объём и строение
- 5–7 глав; в каждой — завязка, 2–4 места, развязка. Всего **120–200 сцен** кампании (с дорожными), 3–6 своих мест
  (из них 2–4 со схемой на 8–25 комнат), 20–40 своих дорожных встреч, использование 6–10 замков книги (через `triggers`
  на `site`/`room` и подмену 3–10 комнат). Длинные разговоры — через `nodes` и `ask` с несколькими ветками.
- Сложность растёт: первые главы — для героев 0–2 уровня (орты, кобольды, гоблуры, разбойники), середина — 3–6,
  финал — для 6–10 уровня (драконы, вахнал, баргул и т. п.). Награды (деньги, бутылочки, волшебные вещи 26–43, ИО)
  — чтобы отряд рос. Опасности — только с карточек (id из zs-monsters.md), имя можно своё (`name`).
- Тон — старая русская сказка в духе советской книжки 1990 года: живо, с юмором, без современных словечек.
  Мир книги: Форпост, трурли с лавками, клурки/маги/кроны, гнум — добрый волшебник, Чёрный маг, его отец РЭД.
