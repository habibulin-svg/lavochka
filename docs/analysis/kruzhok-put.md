# «Путь» кружка — сквозной сценарий обучения (2026-10-22, по просьбе пользователя)

Проблема (пользователь + аудит): кружок — пять разрозненных разделов; новичок не понимает, куда идти, прогресс не виден.
Решение (принято без пользователя, в автономном режиме, — можно пересмотреть): главный экран кружка — **«Путь»**.

## Экран «Путь» (первый раздел)

- Сцена — тетрадный лист с дорожкой по 7 частям учебника. Узлы: **урок** → **задачи** (закрепление урока, 5 задач
  по его темам; у уроков без темы — нет) → в конце части **партия мастера** (классическая партия по теме) и
  **зачёт** (10 задач по темам части). Состояния: пройдено (✓ и звёзды), текущий (подсвечен), впереди (бледный;
  открыть можно, но путь предлагает по порядку).
- Панель: Михалыч с фразой по месту («Начнём с доски» / «Сегодня — вилка»), большая кнопка **«▶ Дальше: …»**,
  разряд и рейтинг, звёзды кружка, серия дней, полоса части, грамоты.
- Части и их партии: I Доска и фигуры — без партии; II Правила — «Партия в опере»; III Первые маты — Рети — Тартаковер;
  IV Тактика — Ласкер — Бауэр; V Эндшпиль — Капабланка — Тартаковер; VI Дебют — «Вечнозелёная»; VII Стратегия —
  Ботвинник — Капабланка.

## Звёзды кружка (видимая награда)

- Урок пройден — 10; «Твой ход» с первой попытки — +2; задача решена с первого раза — +3 (с ошибкой — 1);
  ход мастера найден — 5; зачёт сдан — 30; всплывающее «+N» и счётчик в шапке пути.
- Грамота за часть (зачёт сдан) — в журнале; разряд — как был, по рейтингу задач (до 10 задач — «б/р»).

## Возврат на путь

- После урока, задач, партии — кнопка «Дальше по пути» (следующий узел), а не только «к оглавлению».
- «Разбор» → «Доска с движком»: понятная подсказка, что там делать; «Разобрать в кружке» после партии с ботом.
