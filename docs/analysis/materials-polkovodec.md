## 2. Поле и фишки

### Поле (kartaforpolk.pdf)
- Это **не скан оригинала**, а перерисовка: плоская зелёная заливка, **квадратная сетка 36×27 клеток** (≈295 px клетка, чёрные линии ~5 px), дороги — толстая бежевая линия, пущенная поверх клеток, рельеф — повторяющиеся фото-текстуры одной картинки на клетку (горы, лес, болото, река, дома крепости), 4 моста-текстуры.
- Разрешение **более чем достаточное** (в 295 px клетка; для экрана хватит 100–120 px → 3600×2700). Сетка чёткая, плитки стыкуются без швов.
- **Водяные знаки «printgames.ru»**: минимум 3 места (на дороге в левом верхнем углу, у верхней крепости, на нижней дороге) — вычищать.
- Рельеф (по подсчёту на глаз): ~6 крепостей по 3–6 клеток (дом-текстура, ≈25 клеток), горы ≈60 клеток, лес ≈36, болото ≈15, река ≈65 клеток (течёт сверху-справа вниз) с 4 мостами, дороги 4–5 ветвей. Точную клеточную карту надо снять отдельным шагом (классификация по цвету + ручная правка; автоклассификация дала шум на клетках с дорогой).
- **Что не так:** грубая стилистика (клетка-текстура повторяется «ёлочкой»); дороги идут «мимо клеток» (по правилам нужно решить, какие клетки дорожные); нет подписей и названий; в оригинале поле — три листа, здесь один (при размере 36×27 разбивка на 3 части по 12×27 естественная); часть клеток дорог/крепостей имеет границы «куском» (крепость — кластер, но клетки внутри обведены).
- **Можно взять как есть?** Как геометрическую основу — да (сетка, размеры, положение рельефа). Как «оригинальное поле» — нет: оригинала в материалах нет вообще. Придётся: убрать знаки, заменить дорожные линии на привязанные к клеткам (или оставить линию как есть и ввести таблицу «клетка → дорога»), по желанию сгладить стык текстур. Правило CLAUDE.md «вырезаем со сканов» здесь выполнимо только для текстур самой пересборки.

### Фишки
- **Оригинальные карточки (квадраты на фоне цвета армии с вензелем A/N/F)** — не отсканированы. Образец их вида — только чёрно-белые рисунки на схеме (фигурка + буква в углу + знамя с кружком-подставкой). 
- **Иллюстрации войск (6 листов)** есть для всех 3 армий и **покрывают все роды из таблицы**: русские — мушкетёр, гренадер, егерь, гренадер егерского полка, драгун, кирасир, гусар, улан, казак, единорог (орудие), конная артиллерия; французы — фузелёр, гренадер, вольтижёр, карабинер, драгун, кирасир, гусар, улан, конный егерь, орудие, конная артиллерия; австрийцы — фузелёр, гренадер, егерь, граничар, драгун, кирасир, гусар, улан, лёгкий драгун, орудие, ездящая артиллерия. Фигуры крупные (400–700 px в 2500-пиксельном скане), фон — белая бумага, вырезаются лёгко. Есть и по одному большому знамени на армию (русское, французское «орёл» с древком, австрийское) — это знамя маршала. Генеральские «маленькие знамёна» — на листе знамён (не отсканирован): брать из fishki.pdf стр.7 или нарезать флажок из знамени.
- Плюсы листов: оригинальное исполнение, 3 армии. Минусы: нет карточек-подложек, нет номиналов складов, нет генералов и маршалов отдельными фишками; на фото единорога красные пометки (взять из armii.pdf, стр.2); у французов нет подписи «пушка», только «Орудие».
- Фишки fishki.pdf — готовые квадраты (208 px, в цвете армии, с аббревиатурой), цены в таблице стр.1 не совпадают с оригиналом. Пригодны только как резерв (и армии «англичане», «пруссаки» из них — не из оригинальной игры).

Итог: **оригинальные фигурки — есть; оригинальное поле и карточки — нет** (только пересборка и чёрно-белые образцы). Это не мешает сделать игру, но «вырезаем со сканов» для поля и подложек не получится на 100 %.

## 3. Правила (внутренний документ для движка)

Источники: с.3, с.4, таблица (с.5–6), пример (с.4 и с.6). Если сказано «таблица» — значения берутся из неё; «—»—» (кавычки-повтор) в таблице означают «как в строке выше», я раскрыл их ниже.

### 3.1. Общее (с.3)
- Игра имитирует действия армий 1812–1814 гг.; армии: русская, французская, австрийская. Игроков 2–6 (на каждого — армия; в комплекте всего три, с.3).
- Перед игрой стороны **договариваются о стратегической цели**: разгром противника (уничтожение живой силы и захват укреплений, лишающий формирования новых частей), захват или оборона центрального укрепления (цитадели), занятие территории противника и т. д. (с.3, с.4: «полный разгром противника, оборона крепости или что-то другое»).
- Поле — квадратная сетка клеток (ходят по прямой и по диагонали). Рельеф: реки, болота, горы, леса, дороги, крепости.

### 3.2. Состав и масштаб (с.3, с.4, с.6)
- Один квадратик (фишка) = рота, эскадрон или артиллерийская рота. 2 роты = батальон, 4 роты/эскадрона = полк (в игре не используются как отдельная единица — только пояснение масштаба).
- Знамёна: **одно большое знамя на армию = маршал (фельдмаршал)**, **маленькие знамёна = генералы**. Знамя ставится на подставку (24 фишки в комплекте, на всех).
- **Воинская часть** = одна или несколько **соприкасающихся** фигур, способных одинаково передвигаться. Допустимые сочетания (с.4):
  1. мушкетёр + мушкетёр;
  2. драгун + кирасир + конная пушка;
  3. егерь + гренадер;
  4. гренадер + фузелёр + карабинер + вольтижёр + пушка + драгун + конная пушка;
  5. конная пушка + конный егерь + гусар + улан + драгун.
  (Названия зависят от армии — см. таблицу. Сочетание «гренадер + кирасир» противоречит тактике и не допускается.)
- **Походная колонна**: части любых родов можно объединять, движутся со скоростью самой медленной (с.3). Из походного положения **уничтожить противника нельзя**.

### 3.3. Склады, формирование, снабжение (с.3, с.4, таблица)
- Участники получают «снаряжение» в виде **карточек складов** в количестве по договорённости (пример: по 30 армейских складов; чем больше складов — тем длиннее игра; при игроках > 3 складов берут меньше; более слабому игроку добавляют несколько армейских складов, с.4).
- Типы складов и **мобилизационная способность (МС)**: армейский = 2·корпусной = 4·дивизионный = 10·полковой. В «полковых» единицах: **армейский 10; корпусной 5; дивизионный 2,5; полковой 1** (подтверждено карточками fishki.pdf).
- **Склады — это бюджет**: на фигуры тратятся склады из запаса (таблица ниже, столбец «Расход»); остаток — **стратегический запас** (карточки, лежат у игрока).
- Подготовка (с.4): выбрать армию; положить поле из 3 частей (дороги совпадают); поделить территорию (у каждого примерно поровну городов/крепостей); договориться о запасе складов; сформировать армию — купить фигуры по таблице за склады, вычесть из запаса, остаток — стратегический запас. Для разных задач составы разные: наступление — больше кавалерии и конной артиллерии; горы/леса — конные егеря; оборона — пехота и артиллерия.
- **Формирование новых войск в течение игры** (с.3): только **в своих крепостях**; нужен **приказ генерала** на формирование **или** вместе с новыми частями появляется новый генерал; новые войска **сначала заполняют все клетки крепости, потом ближайшие к ней**; если крепость захвачена и не освобождена — формировать в ней нельзя. Плата — из стратегического запаса по таблице.
- Крепости: в них военные склады. **Захват** — победителю достаются трофеи: **одна клетка крепости = один корпусной склад (5)**. Крепость считается захваченной, если из неё выбиты войска противника и **они вновь не вошли в крепость в последующие два хода** (с.3).

### 3.4. Генералы и маршал (с.4, таблица)
- Генерал отдаёт **один приказ за ход**; все генералы армии — каждый по приказу. **Зона действия приказа — квадрат 13×13 клеток с генералом в центре** (через адъютанта; = «6 клеток во все стороны» из таблицы). **Один приказ = одна воинская часть в зоне делает один ход** (с.4).
- Часть, потерявшая генерала (вне зоны любого генерала/маршала), **деморализована**: не может маневрировать, пока в её зоне не появится генерал.
- **Маршал** = функции генерала + руководит армией. Потеря маршала: генералы **прекращают боевые действия и только выводят части из-под огня**; можно **ввести нового маршала**, потратив воинские припасы (по таблице: 1 армейский + 1 корпусной = 15); иначе армия **капитулирует** (с.4).
- Генерал/маршал как фигура: стоимость генерала 1 корпусной (5), маршала 1 армейский + 1 корпусной (15); ход — **на одну клетку в любом направлении или так же, как та часть, на которой стоит**; **не атакует**; на примере (схема) знамя генерала стоит на карточке части («флажок с кружком»).

### 3.6. Местность (с.3)
- **Горы, болота и овраги** — непроходимы для кавалерии и артиллерии.
- **В горах воевать** могут только егерские части (вольтижёры и карабинеры — франц.; егеря и гренадеры егерских полков — русские; егеря и граничары — австр.) и конно-егерские (казаки — русские; конные егеря — франц.; лёгкие драгуны — австр.). Мушкетёры (рус.), фузелёры (фр., австр.) и гренадеры (все три армии) **могут передвигаться в горах, но не ведут боевых действий**.
- **Водные преграды** — непроходимы для артиллерии. **Фигура, простоявшая два хода подряд на клетке реки, считается утонувшей и выбывает** (с.3; в docx этой фразы нет).
- **Лес**: боевые действия невозможны для всех, кроме егерских и конно-егерских. Артиллерия в лесу не воюет, **за исключением** того, что перед началом игры расставлена на крайней клетке леса — тогда она «в засаде».
- **Дороги**: все войска движутся **вдвое быстрее**; «идущей по дороге» считается только та часть, что **стоит на клетках дороги**. Дорогой считается и вся площадь крепости, через которую идёт дорога.
- **Артиллерия не стреляет через крепости, горы и леса, а также через воинские части** (в том числе, видимо, свои — см. п. 4).

### 3.7. Ход игры (с.3, с.4 пример, с.6)
- Очерёдность: право первого хода выпало русским («предположим», с.4) — разыгрывается жребием/договорённостью. Далее по очереди.
- В свой ход игрок: (а) решает, какие генералы/маршал отдают приказы (каждый один); (б) каждый приказ — одна воинская часть в зоне 13×13 этого генерала делает один ход (перемещение либо взятие); (в) может сформировать новые войска в своей крепости по приказу генерала.
- **Приказы отдаются одновременно** (с.4), поэтому нельзя, например, дать залп из орудий по кирасирам и одновременно послать свои гусары в атаку на улан: «гусары попадут под огонь своих орудий». Выход — манёвр (двумя эскадронами атаковать гусар, два держать в резерве, пушки отвести из-под удара, пехоту выдвинуть вперёд).
- **Проверка по схемам (используйте как тест движка):** схема 1 — поле 6×7, у русских 3 генерала (флажки у гусар, пехоты и батареи). Схема 2 — русские гусары (2 эскадрона) перешли с (2,5)→(5,2) и (2,6)→(5,3) по диагонали на 3 клетки и **заняли клетки двух французских улан** (те сняты с поля — «карточки двух разбитых французских эскадронов снимаются с поля»); пушки сместились на 1 клетку по диагонали; пехота вышла вперёд. Это точно соответствует таблице.
- Исторический комментарий (с.6): эпизод Бородинского сражения — атака кирасир Ватье на батарею Раевского, контратака Сумского гусарского полка Делянова.

### 3.8. Победа (с.3, с.4, с.6)
- Определяется **по договорённости** (стратегическая цель): разгром; захват/оборона цитадели; занятие территории. Формальных очков победы нет.
- Поражение армии: **гибель маршала без замены** (капитуляция); либо исчерпание сил/складов (подразумевается). Игра длится, пока стороны имеют склады; «чем больше складов, тем длиннее игра».

## 4. Пробелы и противоречия (с решениями)

1. **Нет оригинала поля и карточек.** Решение: поле — пересборка kartaforpolk.pdf (подчистить 3 знака; снять клеточную карту 36×27 с типами клеток); карточки собрать как композицию: подложка цвета армии (зелёная/голубая/белая) + вырезанная фигура с листа + буква-вензель (А/N/F) в углу, как на схеме; генералы — карточка с оригинальным флажком (из знамени). Если требуется «ровно как оригинал» — нужно найти листы войск/знамён оригинала (в материалах нет).
2. **«Одновременно» vs очерёдность приказов (с.4).** Пример с «гусары попадут под огонь своих орудий» противоречит запрету артиллерии стрелять «через воинские части» (стрельба своих по своим не нужна). Решение: приказы исполняются **по одному, в выбранном игроком порядке**, ограничение «артиллерия не стреляет через любые части (свои и чужие)» сохранить; «одновременность» в примере трактовать как «один генерал — одно действие за ход, перестраиваться между приказами одного хода нельзя»: порядок исполнения задаётся заранее, не может быть изменён по ходу (как «одновременно» в оригинале).
3. **Один ход части: всей части или каждой фигуре?** «Приказ позволяет воинской части сделать один ход». Решение: приказ активирует **часть целиком**: каждая её фигура может сделать одно действие (ход или взятие) по своим правилам; фигуры части остаются соприкасающимися (диагональ/сторона) либо движутся колонной со скоростью самой медленной.
4. **Диапазон хода: «до» или «ровно».** Решение: **до N клеток** (как в шахматах); минимум 1.
5. **Блокировка пути.** Не сказано, можно ли перепрыгивать фигуры. Решение: движение/взятие **по прямой/диагонали без перепрыгивания**: промежуточные клетки пусты и проходимы; артиллерия — те же условия плюс запрет «через крепость, гору, лес, часть» (таблица+с.3).
6. **Взятие — что делает при не-дальнобойных родах.** Решение: взятие = ход на клетку противника в пределах «поражения»; нужен подходящий рельеф и для атакующего, и для цели; артиллерия бьёт цель на любой из 8 линий до 5 клеток по свободной линии.
7. **Враждебные клетки: можно ли бить цель в лесу/горе/крепости.** Решение: бой возможен, только если **обе клетки (атакующего и цели)** допускают бой для этого рода; егеря/конные егеря/лёгкая пехота могут воевать везде; остальные — только вне леса/гор (в крепости — можно, в крепости нет бонусов).
8. **Конные егеря в горах** («горы непроходимы для кавалерии» против «конно-егерские воюют в горах»). Решение: **конно-егерская кавалерия (казаки, конные егеря, лёгкие драгуны) и лёгкая/элитная пехота проходят и воюют в любой местности** (как в таблице fishki.pdf: «двигается и воюет на любой местности»); остальные: лес/горы/болото закрыты для кавалерии и артиллерии; тяжёлая пехота ходит в лесу и горах, но не воюет.
9. **Овраги** упомянуты, на поле нет. Решение: отдельного типа нет; болото = «овраг».
10. **Засада артиллерии в лесу** — эффект не описан. Решение: стрелять из лесной клетки можно только при расстановке на крайней клетке и пока не двигалась (не стреляет «через лес» для обзора); в бою бонусов нет — отметка «в засаде» только разрешает стоять в лесу.
11. **Мосты** в правилах не упомянуты, но на карте 4 моста. Решение: мост = клетка дороги через реку: не топит, проходима для артиллерии (иначе нечем переправляться); остальные клетки реки — как по с.3.
12. **Река: утопление через 2 хода (есть только на с.3, нет в docx).** Решение: считать «ходы владельца» подряд на клетке реки; перемещение на другую клетку реки сбрасывает? — принять: сбрасывается только выходом на сушу.
13. **Дорожное удвоение**: как считать, если часть пути вне дороги. Решение: удваивается лимит клеток, **пока фигура идёт по дорожным клеткам** (с клетки дороги на клетку дороги; для диагонали дорожными должны быть обе клетки); выход на не-дорожную клетку в середине хода — остаток по обычной норме. Карта: дороги привязать к клеткам таблицей.
14. **Походное положение.** Решение: часть, использовавшая дорожный бонус (прошла дальше обычного лимита), в этот ход **не может брать** (с.3).
15. **Деморализация**. Решение: часть вне зон генералов не может получить приказ, то есть не действует (в тексте «лишается манёвра»); оборонительных бонусов нет; вернуть можно, подведя в её зону генерала (генерал сам ходит приказом или своим ходом).
16. **Ход самого генерала: тратит ли приказ.** Решение: **ход генерала — отдельное действие, оно тратит его приказ за ход** (иначе генерал мог бы передвигать себя бесплатно).
17. **Маршал: «общее руководство»** — формально только функции генерала + нельзя потерять. Решение: приказ маршала действует как генерала; потеря маршала запускает капитуляцию, если нет запаса на нового (15); нового маршала ставят в крепость.
18. **Склады: теряет ли проигравший при захвате крепости** («трофеи достаются победителю»). Решение: победитель получает 5×(число клеток) в запас; проигравший ничего не теряет (как в тексте); альтернативный вариант: перенос с запаса соперника (по желанию в опциях).
19. **Формирование «по приказу генерала».** Решение: формирование — отдельный приказ генерала, у которого крепость в зоне 13×13; либо вместе с новой частью покупается новый генерал (5).
20. **Победа не формализована.** Решение: три режима (опция): «Разгром» (у соперника нет маршала и нет фигур/запаса), «Цитадель» (захват помеченной крепости и удержание 2 хода), «Территория» (держать больше крепостей на ходу N). Для игры с ботами по умолчанию — «Разгром» плюс лимит ходов.
21. **Число складов и состав фигур.** 30 армейских на сторону = 300 единиц — это ≈120 фигур; оригинальные листы вмещают гораздо меньше. Решение: пресеты — малый 8 армейских (80), средний 12 (120), большой 20 (200); при 3+ игроках уменьшать (по тексту).
22. **Расстановка и территории.** «Расставьте на своей территории» — границы не заданы. Решение: поле делится вертикально на равные части (для 2 игроков 18×27, для 3 — 12×27) с равным числом крепостей (±1); расстановка ходом по очереди.
23. **Очерёдность ходов при 3–6 игроках** не описана. Решение: по часовой от первого игрока (жребий).
24. **Армий больше 3**: в комплекте только 3 армии, для 4–6 игроков не хватает. Решение: ограничить 2–3 игроками либо дать дополнительные армии «англичане/пруссаки» из fishki.pdf (не оригинал).
25. **docx-выписка неполная** (нет реки/утопления, нет таблицы). Решение: за основу — фото страниц; docx не использовать.
26. **Таблица fishki.pdf (стр.1) расходится с оригиналом** (артиллерия 5, конная 8, генерал 10 против 10/15/5 в брошюре; «Атака»/«Движение» совпадают). Решение: считать **брошюру** источником истины; значения из fishki — только если захотим вариант «очков».
27. **Нет приоритета цели при нескольких целях/нет «ничьей» и нет лимита ходов.** Решение: лимит 80 ходов на сторону, затем выигрывает тот, у кого больше склады+фигуры (по стоимости); ничья при равенстве.
28. **Пример боя оборван**: ход французов не описан (с.4 заканчивается «пехоту выдвинуть вперёд», с.6 — «этим манёвром сорвали планы»). Решение: достаточно для теста правил (см. п. 3.7), для интерфейса показа правил (demo) — взять схему 1 → 2 как основной пример.
29. **Стоимость конной артиллерии «1 армейский и 1 корпусной»; МС-единицы** — совпадают с карточками fishki, считаем в единицах 1/2,5/5/10 (дробные значения хранить как целые ×2: 2/5/10/20).
