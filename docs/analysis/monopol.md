## Особые поля
- Подвал (Чёрный кот): 7×5, вход в жёлтую клетку справа (ряд 1), выход стрелкой слева из ряда 1 → на Парикмахерскую.
  Ряды (красные «+», синие «−»): `−100 +400 −200 +600 −300 −400 −200 / −600 −100 −300 −200 −300 +500 [вход] /
  +300 −200 +200 [кот] +100 −500 −300 / −300 −400 +300 −700 −600 −400 −200 / −900 +900 −300 +400 −100 −900 +800`.
  6 бросков, после каждого — ход на выпавшее число клеток (не по диагонали, не через кота), деньги по клетке. Не вышел — штраф 500 и наружу.
- Белка в колесе: 8 секторов против часовой стрелки от входа: +200 → −200 → +300 → пусто → −300 → +500 → +100 → −100.
  Бросают, пока не встанут на пустой сектор; выход стрелкой → Старик Хоттабыч.
- Тараканьи бега: дорожка 20 клеток: −100 +100 −300 −200 +1000 −100 +100 −300 +500 +200 −100 +700 −400 +400 +500 −400 −700 +900 ½ ×2;
  бросают, пока не выйдут; ½ — сумма пополам, ×2 — вдвое (последняя). Выход стрелкой → Пекарня.
- Баня: 10 тазиков; со следующего хода по броску идут по тазикам, ход за ходом; прошли 10 — снова на Бане.
- +500 — за попадание и за проход.

## Решения без пользователя
- Сберкнижки: кредит до 2× капитала (наличные + вклады + цена фирм) минус долг. На следующих попаданиях на ту же книжку —
  либо вернуть весь её долг, либо заплатить дробь (1/10 Папина, 1/5 Мамина) от долга как процент (долг не уменьшается).
- Рулетка: ставка только наличными (можно 0 — пропуск), угадал — +5 ставок, не угадал — ставка в фонд.
- Объединение капиталов в группы не делаем.
- Нечем платить: сначала снимаются вклады со своих фирм, потом фирмы уходят в фонд за полцены; не хватило — банкрот, фирмы свободны.
- «Лотерея»: «пропустите ход» — следующий ход пропущен; «в кассу» — в кассу игровых автоматов; «перебросьте кубик» — лотерея заново.
- Конец: все, кроме одного, разорились, или прошло заданное число кругов — побеждает самый богатый (наличные + фирмы с вкладами − долги).
- Попадание по лотерее «на клетку» — без премии за проход +500, действие клетки выполняется.
