# Школа покера — план уроков, формат, правила для авторов (этап 5, 2026-10-22)

Вкладка «Школа» в лобби покера. 12 уроков по пути, каждый: **шаги на настоящем столе** → **5–10 задач «твой ход?»**
(ответ проверяется расчётом) → **игра-закрепление** против ботов нужного стиля. Код — `src/games/poker/school/`,
уроки — `school/lessons/NN-id.json`, образец — `04-auty.json`. Концепция — в духе Харрингтона (M, зоны, инициатива)
плюс современное (ICM, пуш/фолд по Нэшу), **своими словами**, без пересказа книг. Без названий покер-румов.

## Уроки

| № | id | Тема | Главное | Задачи (виды) | Закрепление |
|---|---|---|---|---|---|
| 1 | `pravila` | Правила и комбинации | раздача, блайнды, улицы, вскрытие, лестница комбинаций, кикер, делёж | `combo`, `winner` | быстрая игра, новички |
| 2 | `pozicii` | Позиции | UTG…BB, кто ходит когда, почему поздняя позиция дороже (ходишь последним после флопа) | `position`, `open` | быстрая игра на 6 |
| 3 | `starty` | Стартовые руки и диапазоны | 169 классов, пары/одномастные/разномастные, «диапазон» как доля рук, чем позднее — тем шире | `open` | быстрая игра на 6 |
| 4 | `auty` | Ауты и шансы банка | ауты, ×4/×2, колл/(банк+колл) | `outs`, `potodds`, `callfold` | быстрая игра |

| 11 | `final` | Финальный стол и хедз-ап | скачки выплат, крупный стек давит, вдвоём руки шире | `pushfold`, `open`, `icm`, `position` | хедз-ап турнир |

## Формат урока

```json
{ "id": "auty", "n": 4, "title": "…", "goal": "одна строка",
  "steps": [ { "text": "HTML: <b>, <i>, <br>", "scene": { … }, "play": [ { "act": [0, "call"], "caption": "…" } ] } ],
  "remember": ["3–5 коротких выводов"],
  "tasks": [ { "id": "auty-1", "q": "вопрос", "kind": "outs", "scene": { … }, "options": [["8", "8"]], "answer": "8", "why": "почему" } ],
  "game": { "text": "что делать в игре", "kind": "cash", "bots": ["tag", "station"], "level": 1, "hands": 30 } }
```

- Шагов 4–7, первый — со столом (`scene`); шаг без `scene` продолжает стол прошлого шага (с сыгранными `play`).
- Задач 5–10 (лучше 7–8). Ответ — значение из `options` (или из вариантов по умолчанию для вида, см. ниже).
- `game.kind`: `cash` (быстрая игра: `hands` 20/30/40, `stack` 500/1000/1500/2000, `mode` — вид покера) или `sng`
  (`tour`: `hu`/`sng6`/`sng9`/`don`, `speed`: `normal`/`turbo`/`hyper`). `bots` — стили: `tag` (регуляр), `lag`,
  `nit`, `station` (колл-станция), `maniac`, `fish` (новичок); `level` 0/1/2.

## Стол (`scene`)

Настоящая раздача движка: блайнды и анте ставятся сами, потом ходы `pre` до нужного места.

- `n` — игроков (места 0…n−1, по умолчанию 6). Имена мест: 0 — **«Ты»** (герой по умолчанию), 1 Ленка, 2 Серёга,
  3 Танька, 4 Димон, 5 Колян, 6 Светка, 7 Жека, 8 Михалыч. `hero` — другое место героя (тогда «Ты» — оно, а место 0 —
  Вовка).
- `button` — по умолчанию n−1. **SB = button+1, BB = button+2** (по кругу). Вдвоём баттон — малый блайнд: до флопа
  ходит первым, после флопа — вторым.
- До флопа первым ходит место после BB, последним — BB. После флопа — первый живой после баттона.
- `stack` — число или массив по местам (на начало раздачи); `blinds` — `[малый, большой]`, по умолчанию `[10, 20]`;
  `ante`: `all` (с каждого — десятая часть ББ), `bb` (большой блайнд платит ББ за всех), `button`.
- `hands` — `{"0": "AH KH", "3": "QS QD"}`; карты: ранг `2…9`, `10` или `T`, `J Q K A`; масть `S H D C`.
  Не названные руки — из колоды. `board` — общие карты по порядку (флоп, тёрн, ривер), сжигание — само.
- `pre` — ходы: `[место, "fold"|"check"|"call"|"allin"]` или `[место, "raise", до скольких]`. **Ставка после флопа —
  тоже `raise`**, «до скольких» — сколько всего место поставит на этой улице. `foldTo: true` — после `pre` все до героя
  пасуют. Ход не по очереди — ошибка проверки («ходит место N»).
- `show: 5` — только картинка: сразу открыть 5 (или 3, 4) общих карт, ходов нет (вскрытие, Омаха, стад, дро).
- `open: true` — показать карты всех (в задачах-решениях не нужно: герой видит только свои).
- Вид покера — `mode` (`omaha4`, `stud7`, `razz`, `td27`, …), `hilo: true` — хай-лоу. В стаде `hands` — все 7 карт,
  открытые — 3–6-я (можно `up: {"0": [2,3,4,5]}`); в дро — 5 карт.

## Виды задач (`school/solve.ts`)

| kind | Что считается | Поля | Варианты по умолчанию |
|---|---|---|---|
| `combo` | лучшая комбинация героя | стол с доской | 9 названий: «старшая карта» … «стрит-флеш» |
| `winner` | кто выиграет (движок) | стол, `show`, `open` | места + `split` («Делёж») |
| `winlow` | кто возьмёт низкую половину (хай-лоу) | стол, `hilo` | места + `none` + `split` |
| `outs` | ауты; с `villain` — карты, после которых герой впереди его руки | стол на флопе/тёрне | нужны `options` (числа) |
| `potodds` | колл/(банк+колл), % | стол, где герою доплачивать, или `call` + `pot` | нужны `options` (числа %) |
| `callfold` | шансы против диапазона `vs` против шансов банка | стол + `vs` («QQ+, AKs, AQo, KJs+, 77-55») | `call`/`fold` |
| `position` | позиция героя | стол | UTG, UTG+1, UTG+2, MP, HJ, CO, BTN, SB, BB (по числу игроков) |
| `open` | рейз или пас первым (доля руки против ширины открытия по числу игроков позади) | стол, `foldTo` | `raise`/`fold` |
| `zone` | M и зона (по стеку на начало раздачи) | стол | зелёная, жёлтая, оранжевая, красная, мёртвая |
| `pushfold` | Нэш: все спасовали → `push`/`fold`; один ва-банк перед героем → `call`/`fold`; с `prizes` — по ICM | стол (холдем, ≤ 20 ББ) | по виду спота |
| `icm` | `ask: "max"/"min"` — место с наибольшей/наименьшей долей призовых; `"value"` — доля героя, % | `stacks`, `prizes` | места; для value — `options` |
| `bubble` | фактор пузыря героя (место 0) против `villain` | `stacks`, `prizes`, `villain` | нужны `options` (числа) |
| `betodds` | шансы, которые ставка даёт сопернику: bet/(pot+2·bet), % | `bet`, `pot` | нужны `options` |
| `bluff` | блеф окупается, если пасуют чаще bet/(pot+bet) | `bet`, `pot`, `fold` (0…1) | `bet`/`check` |
| `style` | стиль по VPIP/PFR/AF (`hud.styleGuess`) | `hud: {hands, vpip, pfr, af}` | 6 стилей |

Числовые варианты — ближайший к расчёту; проверка требует запас (варианты не должны быть слишком близко), а решения —
не на волоске (колл/пас — шансы отличаются от нужных хотя бы на 3 п. п., пуш/фолд — хотя бы на 0,25 ББ).

## Проверка

```
npx tsx tools/poker/school-check.ts --only 04 --v
```
Показывает ошибки (карта дважды, ход не по очереди, расчёт не совпал с ответом, на волоске) и с `--v` — расчёт по
каждой задаче: им удобно сверять текст `why`. Урок готов, когда ошибок нет и `why` не противоречит расчёту.

## Стиль текстов

- По-русски, на «ты», короткими фразами, тепло, но по делу; дворовый тон — чуть-чуть, не в ущерб ясности.
- Карты в тексте: **Т К Д В 10…2** и масти **♠ ♥ ♦ ♣** («Т♥ К♥», «пара дам»). Термины — как в интерфейсе: пас, колл,
  рейз, чек, ва-банк, баттон, блайнды, ББ, флоп/тёрн/ривер, C-бет, 3-бет, VPIP/PFR/AF.
- Факты — только те, что совпадают с кодом (расчёт `--v`, `hud.ts STATS`, `calc.zoneOf`, `profiles.ts`).
- Своими словами: идеи (M, зоны, ICM, Нэш) общеизвестны, но текст книг не пересказываем. Без названий покер-румов,
  без «денег» — играем на очки.
