## Правила записи
- Ключ комнаты в `rooms` — id комнаты на плане ('5', '5.1'), поле `id` сцены — `'site:cN:<комната>'`. Сцена нужна для
  **каждого номера, который описан в книге** (и есть на плане). Ненумерованные дворы/коридоры (`c1`…) — без сцены.
- `gm` — текст книги **дословно** (скопируй из txt, исправив только очевидные огрехи распознавания: «вас» вместо «вес» и т.п.).
- Текст для игроков (`say`, строки, `ask`) — по-русски, во втором лице множественного числа, живо и коротко (1–3 фразы на шаг),
  в духе старой сказки и советской книжки 90-х. Игроки видят только то, что видят их герои: без подсказок, которых нет в книге,
  без чисел карточек. Можно добавить запах, звук, деталь обстановки — но не новые факты, меняющие исход.
- Числа (монеты, ОР, проверки «14 и более», БУ, сила 17) — **строго как в книге**. Где книга молчит («требуют денег»,
  «можно присоединиться») — реши сам в духе правил и оставь комментарий `// в книге не сказано: …`.
- «(5)», «(13) (15)» — номера бутылочек и вещей по списку книги: 1–25 → `give: { bottles: [5] }`, 26–43 → `give: { item: 'magic:31' }`.
- «Нападает», «дерётся», «нападают точно» → `fight` (`first: 'foes'`, если нападает сразу / «точно»). Просто имя опасности
  («Липучка.», «Невидимка.», «Дарк») → опиши, кого видят, и реши по правилам агрессивности: `{ aggression: [[...], [...], [...]] }`
  (d6: 1 — спит/не замечает, 2 — замечает, но не нападает, 3–4 — грубит, может напасть (можно `ask`: уйти/драться), 5–6 — нападает;
  последний список ветки — для всех оставшихся граней). Кого-то вроде Кора, Волосатого человека, гнума — мирные (игры, советы).
- «Кор (играет на ОР)», «Волосатый человек играет» → `gamble` (`game: 'hp'` для Кора, `'dice'` — на деньги).
- «Лавка», «Лавка трурля» → `{ shop: { kind: 'trurl', exchange: true } }` и `{ end: true, repeat: true }` (в лавку можно возвращаться).
  «Всё в 1,5 раза дороже» → `markup: 1.5`; продаются бутылки «(5) — 50 золотых» → `kind: 'custom', stock: [{ id: 'bottle5' ... }]` —
  НЕТ: бутылки в лавке — через `ask` с вариантами «Купить (5) за 50» → `take gold` + `give bottles`.
- Сундуки — помощник `chest([...что внутри])` (ключи / «Отпирание» / 1–4 на d6, иначе «тащите с собой»). Если книга
  называет свой способ открыть («Открыть 5, 6», «сила 17») — используй `roll` с этими числами.
- Потайная дверь открывается по ходу сцены → `{ open: '<id соседней комнаты>' }` (проверь по плану, куда ведёт).
  Провалились в яму «(В (17))» → `{ goto: '17' }` в конце ветки.
- Бой с наградой: деньги после победы — `give` в `win`; трофейное оружие — `item: 'loot:sekira'` с понятным именем нельзя,
  поэтому лучше волшебные вещи книги или просто описание.
- Спутники («Гном идёт с вами», «освобождённый эльф служит вам», «2 человека — могут пойти с вами») → `join`
  (`id` латиницей, `name`, `hp` ('2d6' и т.п.), `kd`, `dmg`).
- Если сцена повторяется при новом входе (лавка, трактир, ночлег) — `{ end: true, repeat: true }` в конце.
  Иначе после сцены комната «пустеет» — допиши `after` (что видно при повторном входе), если есть что сказать.
- `who: 'each'` — каждый герой решает/бросает за себя (выпить ли бутылку, «кидает каждый»). Внутри ветки `{name}` — этот герой.
- `bot` у варианта — насколько боту нравится вариант (по умолчанию 1), `risky: true` — опасный (осторожный бот избегает).
- Ночные события («Из камина ночью — фоербарт») → `{ if: { night: true }, then: [...], else: [...] }`.
- Ведущий-человек тоже играет по этим сценам; решения «по усмотрению ведущего» → `ask` с `who: 'gm'`.

## Добавлено в язык по просьбам авторов
- `{ each: [...] }` — шаги для каждого живого героя по очереди; условие `{ hp: { lt, gte } }`; `give.hpSet` («у всех по 1 ОР»);
  `give.revive` (оживить павших/окаменевших), `give.doubleGold`; `take: { gold, pool: true }` — общий платёж отряда;
  флаг `closed:<место>` — замок рухнул, войти нельзя; `roll kind 'hit'` сам считает КД цели и поправки; `give.hp: '-1d3'`.
