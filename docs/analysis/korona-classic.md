## Правила, которых нет в упрощённом движке (по `orig.txt`)

- Путник: карта (характер: добрый/нейтральный/злой, честный/нечестный, терпеливый/нетерпеливый; ПЖ/ПС/ПУ/ПМ, талеры, место старта, особенности, личный предмет). ПО на старте 0. Первой ходит дама (если одна), иначе жребий; по часовой.
- Ход: кубик, движение в любую сторону; межмировые лазарет/заготконтора — одно поле; «остановиться проходом» на лазарете, заготконторе, обменном пункте, провале и на полях, названных в картах.
- Миры: в Мире Силы действуешь ПС, Ума — ПУ, Магии — ПМ. Мир Золота: условия поля можно не выполнять (кроме полицейского участка).
- Карты приключений: 1/2/3 карты по номеру (по возрастанию); «можешь» — по желанию, отказ — карта остаётся на поле; уходя с поля посреди серии — неиспользованные остаются; пришёл на поле с лежащей картой — выполняешь её вместо условия поля (несколько — по номерам); идущий «строго определённым направлением» (очарованность, лицей…) — карты «Если ты выполняешь условия другой карты…» в середину колоды; предмет/друг из колоды — брать или оставить; карты, которые нельзя выполнить сразу, — у себя.
- Битва: противник — свой показатель по миру + кубик (кидает следующий игрок); путник — свой + предметы (при достаточных ПО) + друзья ВМЕСТЕ + кубик. Больше — победа, меньше — поражение, равно — ничья (карта остаётся). Трофей — карта противника; сдача в заготконторе или на полях с карты; ПО за победу — после сдачи трофея (если не сказано иначе). Охота — только с огнестрельным (кольт, бластер…) или другом-охотником.
- Лимит 14 собственных ПС/ПУ/ПМ/ПО до Провала (корона регента снимает лимит своего мира при ≥ нужных ПО).
- Правило компенсации: нет ПС → ПУ или ПМ (1:1); нет ПМ → ПС или ПУ; нет денег → ПУ (1 за 5 т.); ничего нет → ПЖ; нет магпредмета/амулета → 2 ПМ; нет предмета → 2 ПС; нет лошади/друга → 1 ПС. Опыт неприкосновенен.
- ПЖ = 0 — смерть: выход из игры или новая карта путника с начала.
- Безумие (ПУ = 0): не покидает Мир, идёт по часовой к лазарету, выполняя поля; потеря ПУ — ПЖ (1:1); телепортации/искривления/очарованность не действуют; в лазарете бесплатно до 3 ПУ (ПЖ до 4 — за деньги).
- Друзья: по характеру («друг для добрых, для прочих враг»); ВМЕСТЕ (суммируются) или ВМЕСТО (своими пунктами, без твоих предметов); друг-боец погиб — карта в отбой; вничью с путником — уходит; сменил характер — друг уходит; в Провал не идут (остаются на соседнем поле); натравить друга на путника на том же поле.
- Предметы: без лошади/друга — не больше 4 (предметы + магпредметы + принадлежащие + амулеты); один магпредмет; бонусы — при достаточных ПО; принадлежащие владельцу теряются только по картам/полям.
- Дуэль: вместо хода, на том же или соседнем поле, добрые с добрыми не дерутся; проигравший −1 ПЖ, победитель его берёт; в лазарете, заготконторе, обменных пунктах нельзя.
- Перевал и Храм Бааля — пройти за один тур (сколько бросков ни понадобится), без предметов, амулетов и свойств путника.
- Обменный пункт — покупка пунктов по 5 т. (до 14). Лазарет — бесплатно ПУ до 3 безумному, ПЖ до 4 по 2 т.
- Банк и чёрная касса: деньги копятся на поле; ограбление — победить всех охранников, проиграл одному — −1 ПЖ, конец.
- Торговые сделки: на том же/соседнем поле; трофеи, предметы, магпредметы, амулеты (не принадлежащие владельцу), цены договорные; друзья и пункты — нет. Инфляция — округление вверх.
- Провал: собственные ПС, ПУ, ПМ, ПО 11–14 (точный порог — по полю). Друзья остаются на соседнем поле.
- Эмбер: ограничения снимаются, ПО откладываются; дорога — по броску, развилки чёт/нечет, условия строго; погиб — конец. Столица: карта принца (свои ПЖ, ПС, ПУ, ПМ прибавить), лавка — всё на ПЖ по курсу. Лабиринт: один круг за ход. Дворец: первый принц идёт по покоям, остальные — на арену (ждут или бьются с Королём). Коронация: закрываются все Провалы.
- Битва за корону: король дважды бросает, претенденты дважды по очереди; у кого сумма меньше — −1 ПЖ; несколько ниже одного — все по −1; все равны — все по −1; двое-трое равных, но выше остальных — равные по −1, остальные по −2; до последнего живого.
- Приложение (дополнения к картам №1…196) — в `orig.txt` после «ПРИЛОЖЕНИЕ».

## Архитектура (план)

`src/games/korona/classic/` — отдельный движок, def.ts переключает по опции `rules: 'classic'`.
- `data/adventures.ts` — карты: текст + сценарий (массив операций), генерируется из `adventures.json` + ручная разметка.
- `data/items.ts`, `data/heroes.ts`, `data/cells.ts`.
- `script.ts` — интерпретатор операций со стеком кадров в состоянии (сериализуемо): операция, требующая решения игрока, ставит `prompt` и ждёт действия.
- Операции: `add` (пункты/талеры/ПО, потеря — через компенсацию), `convert`, `set`, `roll` (1 или 2 кубика, ветви), `if` (характер, пол, честность, терпение, имеет лошадь/друга/предмет/шлем/огонь/огнестрел/амулет/магпредмет/трофей, ПО ≥ n, ПУ = 0, «выполняет другую карту»), `choice` («можешь»), `battle` (противник, «всегда нападает»/охота, бой показателем, запреты помощи, несколько противников), `move` (на поле, домой, на любое поле, к ближайшему из, на соседнее, N полей по часовой) + выполнение условий поля, `skip`, `status` (длительные эффекты), `card` (отбой/оставить на поле/в середину колоды/поселить на поле/взять с собой: трофей с ценами сдачи, друг, предмет, пропуск в Пещеру сокровищ), `align`, `item`, `all` (все путники Мира), `contest` (все бросают дважды), `special` (ручной код).
- Длительные статусы героя: паралич (нужно 2d6 ≥ n), проклятие мира, только чётные шаги, по часовой (сонная болезнь, безумие), назвать число (дракончик, подкова, дракон удачи), невезение, чёрный двойник, человек-змея, сухотка/дурной глаз/паразиты (потеря перед ходом до поля), маршрут регента, долг/налог/инспекция (Провал закрыт), нет золота до Храма Бааля, амулеты без силы, предметы без силы (ремонт), лимит 8 (воин Хаоса), ворон, зелёная комета (глобально), буря колдовства (глобально).
- Карты на полях: `field[cell] = [{card, payload}]` (деньги под охраной, ПЖ источника, пункты волколака).
