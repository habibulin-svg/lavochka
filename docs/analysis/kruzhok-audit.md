# Аудит «Шахматного кружка» (2026-10-22)

Только чтение кода и данных. Состояние: этапы 1–5 сделаны (последний коммит ed5a78f), этап 6 (SEO, адреса разделов) — незакоммиченная работа в `routes.ts`, `pages.ts`, `index.ts`, `lessons.ts`, `partii.ts`, `encyclopedia.ts`. Его здесь не оцениваю.

## 1. Инвентаризация

### Разделы (`src/games/kruzhok/index.ts`, рамка аркады, 6 режимов)
| Раздел | Файл | Что умеет |
|---|---|---|
| Задачи | `trainer.ts` (385 стр.) | подбор по рейтингу ±100…600 или по теме (50 тем в 4 группах). Первый ход делает соперник. Неверный ход остаётся на доске, Stockfish показывает опровержение, ход можно вернуть. Есть подсказка и «Показать решение». Решённую задачу можно открыть в разборе. Михалыч: «Куда смотреть?», «Почему это ошибка?», «В чём идея?» |
| Учебник | `lessons.ts` + `lessons/*.json` | оглавление по частям. Урок — шаги на доске: стрелки, подсветка, показ ходов, «Твой ход» с подсказкой. В конце «Запомни» и закрепление задачами по теме (`drill`). Михалыч: «Объясни иначе» |
| Партии | `partii.ts` (364) | листание партии и шкала оценки. В остановках — «А как сходил бы ты?»: ход ученика оценивает Stockfish, ходы дальше открытого места скрыты. Михалыч: «В чём идея хода?» и подсказка |
| Разбор | `analysis.ts` (219) | доска с движком: глубина 18, MultiPV 3, стрелка лучшего хода, своя позиция по FEN |
| Энциклопедия | `encyclopedia.ts` (222) | дебюты: поиск по названию, ЭКО и ходам, дерево «семейство → варианты», переход в разбор. Словарь терминов |
| Журнал | `journal.ts` (89) | разряд, рейтинг, график, лесенка разрядов, успехи по темам, сброс журнала |

Общий код шахмат: `chess/board.ts` (доска, только нажатия, без перетаскивания), `notation.ts` (FEN/UCI/PGN, русская запись), `stockfish.ts` (Worker, очередь, cancel), `facts.ts` (доска словами для Михалыча), `mihalych.ts` (клиент), `coach.ts` (Михалыч в партии с ботом). Сервер — `server/mihalych.ts`: роутер, учёт `ai_usage`, лимиты 30 ₽ на ученика и 3000 ₽ на сайт, частотный тормоз. Объём кода кружка — около 2050 строк TS и 113 строк CSS.

### Данные и вес загрузки
- `public/kruzhok/puzzles.json` — 904 КБ (~300 КБ gzip). Грузится **целиком**: в задачах, в журнале (ради счёта по темам) и при закреплении урока.
- `openings.json` — 1,05 МБ (~141 КБ gzip), плюс при открытии `lineRu` по 3865 линиям. Термины (37 КБ) ждут загрузки дебютов (`encyclopedia.ts:209`, `Promise.all`).
- `games.json` 8 КБ + `games/*.json` по 4–8 КБ (всего 284 КБ). Уроки — отдельными чанками через `import.meta.glob`.
- Stockfish 19 lite single: `.wasm` 1,85 МБ (~1,2 МБ gzip) + 28 КБ JS. Грузится лениво; при уходе из кружка `quit()` выгружает его из памяти.

### Конвейеры (`tools/kruzhok/`)

- `tests/mihalych.test.ts` — 7 проверок: доступ, лимит и «запой», безлимит, частота, сборка промпта, месяц по МСК.

## 2. Оценка глазами пользователя

**Новичок / ребёнок с родителем.** Ценно: настоящий учебник от доски до стратегии, «Твой ход» на живой доске, тёплая подача кружка, бесплатно и без входа. Слабо:
- Первым открывается раздел «Задачи» (порядок в `MODES`), а не учебник.
- Стартовый рейтинг 1200 сразу даёт «I юношеский разряд (предварительно)» (`rating.ts:41`, `rankOf`): разряд без единой решённой задачи обесценивает лесенку.
- Уроки фигур (1–7) — по 2 упражнения и без закрепления. Детским курсам (Сухин, ChessKing «Шахматы для детей», Lichess Learn — «собери звёздочки») нужны десятки мини-упражнений на каждую фигуру.
- Нет игры с ботом из кружка, нет грамот (они были в плане), нет звёзд и наград за уроки.
- Журнал живёт только в localStorage. Safari на iOS стирает его после 7 дней без визитов. Для родителя потерять прогресс ребёнка — главная причина уйти.

**Любитель (1000–1600).** Ценно: 6000 задач с рейтингом и темами, разбор ошибки движком, «А как сходил бы ты?» на классике, поиск дебютов по-русски. Не хватает:
- повтора ошибок («Работа над ошибками»);
- серий и режима на время (Puzzle Storm/Rush);
- задачи дня;
- разбора своих партий: в разборе нет вставки PGN, после партии в «Шахматах» нет кнопки «Разобрать в кружке»;
- статей о дебютах — сейчас только названия и ходы.

**Разрядник (1800+).** Задачи до 2999 — хорошо. Но:
- Партий всего 37, и вопросы часто приходятся на вынужденные ходы.
- Нет «доиграй позицию против движка»: Лусена, Филидор, король и пешка.
- Нет дерева дебюта со статистикой, нет этюдов и композиций (в плане были, `classic/*.json` не сделан).
- Против Lichess и Chess.com кружок здесь не конкурент. Его козыри — русская подача, Михалыч и связность.

**Связность разделов.** Связей мало:
- Ссылки есть: урок → задачи (`drill`), термин → урок (70 из 80), задача → разбор, дебют → разбор.
- Обратных нет: задача по теме «вилка» → урок 26, урок → термины и партии, партия (есть `eco`) → дебют в энциклопедии.
- Обычные «Шахматы» и кружок между собой не связаны: в `chess/view.ts` нет ссылки на кружок, общий у них только Михалыч.
- Михалыч есть во всех разделах — это сильная сторона.

**Прогресс и мотивация.** Лесенка разрядов и график рейтинга хороши, но разряд зависит **только** от задач. Учебник и партии в него не входят: отметка «пройден» и счёт «найдено N из M».

**Мобильность.** Одно правило `@media (max-width:900px)` (`kruzhok.css:81`): доска `min(100vw, 75vh)`, панель с текстом урока и Михалычем — под доской, то есть на телефоне нужна прокрутка между доской и текстом. Ходы только нажатием (без перетаскивания). На настоящем телефоне в этой ревизии не проверял.

**Доступность.** Доска — SVG без клавиатуры и ARIA. Нельзя ввести ход текстом («Кf3»), сообщения не озвучиваются (`aria-live` нет). Стрелки различаются только цветом.

**Производительность.** Терпимо: около 300 КБ gzip задач на вход в раздел и 1,2 МБ движка при первой ошибке или разборе. Журналу задачи целиком не нужны. Энциклопедия держит словарь терминов, пока не загрузятся дебюты.

**Монетизация (Михалыч — Лавочка+).** Учёт, лимиты и «запой» сделаны аккуратно и покрыты тестами. Но:
- без подписки Михалыч — только приглашение, попробовать нельзя, а без пробы конверсия будет низкой;
- точки входа есть только в кружке и в партии с ботом;
- карточки расхода в админке нет (только `/api/admin/mihalych`).

## 3. Качество контента (выборка)

**Уроки** (прочитаны 6, 12, 14, 26, 37, 41, 46, 51). Шахматно в основном верно: проверил маты рокировкой (12), взятие на проходе с шахом (14), вилку пешкой (26), оппозицию (37), Филидора (41), отсталую пешку d6 (51). Язык ровный, в стиле Михалыча. Ошибки и слабые места:
- **Урок 6, шаг 1:** «смотри подсвеченные поля» и «восемь полей», а на доске только 2 стрелки (d4f5, d4b3), подсветки нет.
- **Урок 41, шаг 5:** пример «ладья не на шестой» показывает линейный удар по ладье a7. Это не та опасность, от которой спасает схема Филидора (прорыв короля на 6-ю): методически сбивает.
- **Урок 37, шаг 7** — пустая фраза («кто занял — не спешит…»). Ключевые поля упомянуты, но не показаны.
- **Однотипность и тонкость:** почти все тактические уроки (23–35) — по 6–7 шагов и ровно 2 «Твой ход». В 51 и 53 — по одному. Для учебника «до разряда» этого мало: у Сухина и ChessKing на тему приходится 10–30 позиций. Подтверждаются слабости, которые записаны в STATE (30, 33, 35, 53).
- **«Твой ход» засчитывает только перечисленные ходы.** Другой сильный ход получает «не то» (`lessons.ts`, `onPlayer`), а `lessons-check` проверяет только силу засчитываемых, но не то, что нет равных им.

**Партии** (прочитаны «Бессмертная», «Опера», Ботвинник — Капабланка 1938, Ботвинник — Таль 1960). Вступления и итоги хорошие, Бессмертная и Опера прокомментированы связно. Системные проблемы конвейера (`tools/kruzhok/games.ts:173–188`):
- **«!!» ставится по разрыву с вторым ходом движка** (gap ≥ 250). Исключение для взятия-в-ответ действует только на остановки, а на пометки — нет. Итог: 228 из 485 пометок — «!!». «!!» стоят на рутинных взятиях (`botvinnik-capablanca` полуход 10 — b:c3; `botvinnik-tal` 26 — Ф:d3, 57 — Л:c1; `morphy-opera` 20 — С:b5+) и на вынужденном ответе проигрывающих (`morphy-opera` 29 — К:d7).
- **Знаменитые ходы не становятся вопросами.** В партии «Жертва слона на a3» сам ход 30.Сa3 (полуход 58) — только «!», без вопроса и без комментария. Вопросы стоят на ходах короля в конце (68, 74, 80). В «Жертве коня на f4» ход 21…Кf4 (полуход 41) не отмечен и не прокомментирован. Остановки выбираются по «единственному ходу», поэтому в выигранных позициях они уходят в вынужденное, а не в идеи, ради которых партию открывают.
- **Ошибка комментария:** `botvinnik-capablanca-1938`, полуход 73 (ход чёрных d3e4) описан как «король белых берёт пешку h5». Ещё «?» на 28.Фe5 (полуход 56) — ход из победной линии; пометка взята по потере оценки при большом перевесе.

**Термины.** 80 коротких верных статей («Правило 50 ходов» — «можно потребовать ничью», без 75 ходов, приемлемо). Картинки только у 10. Нет ходовых терминов: рентген (есть в темах задач), батарея, вечный шах, висячие пешки, пешечный штурм, перегрузка. Обратных ссылок из уроков на термины нет.

## 4. Технические риски и долги

1. **Гонка в решалке** (`trainer.ts`, `sel.onchange` → `next()`). Если сменить тему во время `sleep(700)` в `next()`, `sleep(600)` в `onPlayer` или анимации `solution()`, два потока работают с одной `pz`/`ply`. Второй `opponent()` играет за ученика его же ход из решения, дальше очередь ходов сбита, возможен «зачёт» без решения. Нужен счётчик поколения задачи.
2. **Рейтинг можно «выбирать».** Сменить тему, раздел или перезагрузить страницу до первого хода — задача пропущена без штрафа (`recordPuzzle` вызывается только при ошибке, подсказке или решении).
3. **Журнал только в localStorage** (`progress.ts`, `kruzhok.lessons`, `kruzhok.classics` — три ключа). Синхронизации нет, хотя журнал обещает «скоро войти» (`journal.ts`). На iOS данные стираются (ITP).
4. **Пометки и остановки партий** — см. п. 3: доверие к «!!» и вопросам подорвано.
5. **Контент вне `npm run check`.** Законность уроков, JSON партий и ссылки терминов проверяются только ручными инструментами. Правка урока руками или агентом может сломать шаг незаметно.
6. **Stockfish:**
   - нет тайм-аута загрузки: если `.wasm` отдаётся не тем MIME или висит, `boot()` ждёт вечно;
   - `quit()` (`stockfish.ts:139`) обнуляет `job`, не отклонив промис;
   - MIME на nginx ещё в списке «проверить на проде».
7. **Энциклопедия:** термины ждут 1 МБ дебютов и падают вместе с ними (`encyclopedia.ts:209`).
8. **Михалыч:** клиент присылает `history` с ролью `mihalych`, сервер кладёт его в реплики ассистента (`server/mihalych.ts:127`). Подделка «слов Михалыча» возможна, но вред ограничен лимитом (6×600 знаков) — низкий риск. «Подсказка не в зачёт» считается на клиенте — для рейтинга это нормально.
9. **`seo.ts` кружка устарел:** описывает только задачи и разбор (этап 1). Касается этапа 6, отмечаю для полноты.
