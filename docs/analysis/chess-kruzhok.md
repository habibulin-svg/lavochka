# «Шахматный кружок» — план модуля (2026-10-21, по просьбе пользователя)

Крупный модуль рядом с шахматами: учебник от правил до стратегии, задачи с рейтингом, разборы классических партий
с остановками «А как сходил бы ты?», энциклопедия с поиском, прогресс. Плюс ИИ-помощник «Совет Михалыча» для подписчиков.
Название и подача — кружок при Доме пионеров: тетрадь, журнал кружка, разряды, грамоты; руководитель — Михалыч.

## Решения пользователя (2026-10-21)

- Название — **«Шахматный кружок»** (не «Школа шахмат»).
- Материалы: задачи — база Lichess (CC0), дебюты — Lichess chess-openings (CC0), движок — **Stockfish WASM в браузере**
  (npm `stockfish`, GPLv3: отдельный файл + ссылка на исходники) и он же на ПК для разметки партий. Партии — старые
  (до ~1950), комментарии свои. Скачивать разрешено.
- Доступ: **кружок бесплатно всем** (учебник, задачи, партии, энциклопедия, разбор движком), **Михалыч — только Лавочка+**
  (право `ai`).
- Место: **отдельная карточка** «Шахматный кружок» в «Доске и костях» + свои SEO-страницы.
- Михалыч: модель `~deepseek/deepseek-v4-flash-latest` через routerai.ru (ключ — в `secret-gui`), лимит **30 ₽/мес** на
  подписчика (цены: вход 10 ₽, выход 21 ₽, кэш 2,13 ₽ за 1 млн токенов). При превышении — понятное «Михалыч в запое до
  1-го числа, потому что…». В оферте и на странице подписки — без моделей и цифр лимита («разумное использование»).
- Михалыч и **в обычных шахматах** (модуль `games/chess`, партия с ботами): разбор хода, подсказка, разговор по ходу партии.
- В админке — право **`ai_unlimited`** («Михалыч без лимита»), выдаётся вручную; у Мастера безлимит всегда (`hasRight` пускает `master` везде).
- Robokassa: подписка на модерации; боевой режим (`ROBOKASSA_TEST=0`) пользователь включает сам после одобрения.

## Устройство

- `src/games/kruzhok/` — модуль со своим экраном (как аркада: `ArcadeModule`, разделы — `modes`, без рекордов).
  Разделы: **Учебник · Задачи · Партии · Энциклопедия · Журнал** (прогресс). Боковая панель — текст урока/хода и Михалыч.
- Доска — переиспользуем отрисовку и правила `games/chess` (`engine.ts`: ходы, FEN, SAN) — вынести общий
  виджет доски (`chess/board.ts`): показ позиции, стрелки, подсветка, ход мышью/тапом, перевёрнутая доска.
- `src/games/kruzhok/sf.ts` — Stockfish в Worker, грузится лениво только в кружке/разборе: `analyse(fen, {depth|ms, multipv})`
  → оценка, лучшая линия. Файлы движка — `public/stockfish/` + `LICENSE`/ссылка на исходники.
- Данные (статикой, кусками, грузятся по требованию): `public/kruzhok/`
  - `puzzles/<тема>.json` — выборка из Lichess: ~5–8 тыс. задач по темам и рейтингу (FEN, ходы UCI, рейтинг, темы).
    Тема «мат в 1/2/3», вилка, связка, двойной удар, отвлечение, завлечение, жертва, эндшпиль и т. д.
  - `classic/*.json` — классические композиции (Ллойд, Сэм Лойд, этюды Ретина и др. — только старые, до 1950).
  - `games/<id>.json` — партии: PGN + ключевые моменты (по разметке Stockfish) + комментарии.
  - `openings.json` — ECO-дерево (код, название по-русски, ходы, FEN) + статьи по главным дебютам.
  - тексты уроков и энциклопедии — `src/games/kruzhok/content/` (TS/MD), пишут агенты на Sonnet по общему плану.
- Прогресс: локально (`store`) + в базе для вошедших (как сохранения `site/saves.ts`): пройденные уроки, решённые
  задачи, **рейтинг задач** (Glicko-2, старт 1200), серия дней, разряды кружка (б/р → III → II → I → КМС по рейтингу).
- **Михалыч** — `server/mihalych.ts`: `POST /api/mihalych` (вход + право `ai`), клиент шлёт **данные, а не текст
  подсказки**: вид запроса (`mistake` / `hint` / `explain` / `chat` / `game`), FEN, ходы, оценки и линии движка, тема урока,
  до 8 последних реплик, вопрос (≤ 500 знаков). Сервер собирает промпт сам: неизменная системная часть первой (кэш),
  ходы — в русской нотации. `max_tokens` ~400. Учёт — `usage.cost` из ответа routerai, копейки за календарный месяц (МСК)
  в базе; потолок 30 ₽/пользователь и общий потолок сайта в месяц (переменная). Нет ключа — Михалыч выключен.
  Портрет — кадр из видео холдема (`public/video/holdem/mihalych`).

### Образ Михалыча (для системного промпта)

Руководитель дворового шахматного кружка, пенсионер, бывший слесарь-инструментальщик и перворазрядник, полжизни
играл на лавочке у подъезда и в парке. Говорит просто и тепло, на «ты», коротко; любит присказки («Конь — фигура
хитрая», «Не спеши, ферзь не убежит»), хвалит за находки, ошибку называет прямо, но без насмешки. Не ругается, не
поучает свысока, не пишет простыней. Объясняет идею, а не сыплет вариантами; ходы называет только из данных движка.
Не знает — так и говорит. Не обсуждает ничего, кроме шахмат и кружка, — мягко возвращает к доске.

## Этапы

1. **Фундамент** — общий виджет доски, Stockfish в Worker, загрузка данных (скрипт `tools/kruzhok/`), карточка и экран
   кружка с разделами, раздел «Задачи» (решение, рейтинг, темы, серия), журнал прогресса локально. Ключ `ROUTERAI_API_KEY`
   в `secret-gui`.
2. **Михалыч** — сервер (`server/mihalych.ts`, учёт, лимит, тесты), панель чата в кружке, кнопки «Почему это ошибка?»,
   «Подскажи», «Спросить Михалыча»; в шахматах с ботами — разбор хода и разговор. Оферта и «Подписка» — пункт про
   помощника и разумное использование.
3. **Партии** — 40–60 классических партий (Андерсен, Морфи, Капабланка, Алехин, Ботвинник, Таль до 1960 — только факты
   ходов), разметка Stockfish на ПК → ключевые моменты, комментарии Sonnet по данным движка; режим «А как сходил бы ты?».
4. **Учебник** — ~50 уроков от простого к сложному (доска и фигуры → правила → мат → тактика → эндшпиль → дебют →
   стратегия), каждый — текст + пошаговый показ + упражнения (задачи по теме). Сначала единый план, глоссарий и стиль,
   потом тексты пачками — для связности.
5. **Энциклопедия** — дебюты (ECO-дерево с поиском), термины, эндшпили, фигуры; от простого к сложному, перекрёстные ссылки.
6. **SEO и выпуск** — страницы `/shahmatnyj-kruzhok/…` (уроки, дебюты, партии — `ARTICLES`/свои маршруты), названия, превью,
   новость, прогресс в базе для вошедших, разряды и грамоты.
7. **Личный маршрут от Михалыча (просьба пользователя 2026-10-22, по образцу «тренера» — от партий к тренировке).**
   В любой момент ученик спрашивает «Что мне подтянуть?» — Михалыч собирает индивидуальный маршрут из нашей базы.
   - **Что копим** (уже есть, для вошедших — в базе через `kruzhok/cloud.ts`): задачи по темам (с первого раза / с
     ошибкой), рейтинг, уроки, ходы в партиях мастеров, штурм, этюды. **Добавить:** партии ученика с ботом в «Шахматах»
     и «Доиграй» — после партии Stockfish в браузере (неглубоко) отмечает ошибки и классифицирует: зевок фигуры,
     пропущенная тактика (вилка/связка/мат — по `chess/facts.ts`), упущенный выигрыш в эндшпиле, фаза партии, дебют и
     итог по дебютам. Хранить сжато (типы ошибок и счётчики, последние N партий ходами).
   - **Профиль считает код, не модель:** слабые темы (точность в теме против рейтинга), частые типы ошибок, фазы,
     дебюты с плохим итогом; заброшенное (учебник встал на уроке N).
   - **Кандидаты подбирает код:** уроки по слабым темам (`THEME_LESSON`), задачи слабых тем у рейтинга ученика,
     этюды по уровню, партии мастеров с нужными идеями, свои ошибочные позиции на повтор — каждому id.
   - **Михалыч** получает короткий профиль + список кандидатов с id и пишет маршрут из 5–7 шагов своим голосом
     («вилки видишь через раз — вот урок 24 и десяток задач»); сервер оставляет только id из списка (выдумать
     материал нельзя). Один запрос ≈ 0,05 ₽, в учёт `ai_usage`.
   - **Маршрут на экране** (раздел «Путь» или «Журнал»): шаги-кнопки открывают урок/подборку задач/этюд/партию,
     отмечаются по мере прохождения; пересборка — через неделю или по кнопке «Что мне ещё подтянуть?».
   - Только «Лавочка+» (право `ai`); без подписки — профиль слабых тем показываем, маршрут от Михалыча — нет.
