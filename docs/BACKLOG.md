### Г*вно (на внимательность) — правила пользователя
- 1 колода; в игре 4 × N карт (3 игрока — 12 карт, 4 — 16 и т. д.: по четыре карты каждого достоинства, достоинств столько, сколько игроков). Старшинство 2…Т (значения не имеет, важны только четвёрки). Игроков 3+.
- Первый сдатчик — жребием, дальше сдаёт проигравший прошлую партию. Каждому по 4 карты.
- Первым ходит сдатчик: кладёт любую свою карту рубашкой вверх. Следующий по часовой делает то же, и они меняются выложенными картами. Затем ход переходит к следующему: он кладёт карту, его сосед — тоже, обмен. И так по кругу.
- Кто собрал 4 карты одного достоинства — резко сбрасывает их на стол с криком «Г*вно!». Остальные повторяют; кто сбросил последним или перепутал — проигравший, «г*вно».
- В браузере: игра на реакцию — кнопка/клавиша «Г*вно!», замер времени (сеть — по времени хоста с поправкой на пинг), фальстарт = проигрыш. Боты: реакция по уровню (лёгкий 1–1,5 с, сложный 0,3–0,5 с).

## Волна 9 — бридж
Роббер, Чикаго (4 сдачи), спортивный (дупликат, для ботов), мини-бридж для обучения. Торговля — упрощённая «Стандартная американская» для ботов; запись — «мы / они». Боты на розыгрыше — двойной болван/поиск по скрытым картам (Монте-Карло).

## Волна 10 — ещё покер
К покеру из волны 3 (холдем, 3D): Омаха (4 и 5 карт), стад (5- и 7-карточный), дро (пятикарточный классический), лоуболл (2–7 triple draw, A–5, разз), HORSE (ротация), бадуги (+ бадэйси, бадуги-хай-лоу). Хай-лоу (8 или лучше) — там, где уместно: Омаха, стад. Одна карточка «Покер», вид — пресетами.

## Волна 11 — пасьянсы
Одна карточка «Пасьянсы» (или по карточке на пасьянс — решить по лаунчеру): косынка (1/3 карты, Вегас), паук (1/2/4 масти), солитёр (FreeCell), пирамида, три вершины, гольф, сорок воров (+ шестьдесят воров), скорпион, колодец.
- У каждого — настройки вариантов и **уровни сложности**: на лёгких вмешиваемся в раздачу (как в косынке Microsoft: только разрешимые раздачи / подкрученные). Нужен решатель на каждый пасьянс, чтобы отбирать сиды по сложности.
- Рекорды: время, ходы; дуэль на одинаковом сиде.

## Волна 12 — го, рэндзю, яхтзи, манкала
- Го (9×9, 13×13, 19×19; японский/китайский подсчёт; фора камнями). Боты — MCTS (на 19×19 сильного не будет, честно указать уровень).
- Рэндзю (с фолами для чёрных) + гомоку/«крестики-нолики на бесконечном поле» вариантом.
- Яхтзи (+ «покер на костях»/генерала вариантом).
- Манкала: калах, оваре (Oware) — пресетами.

## Волна 13 — советские игровые автоматы
- Зал с кабинетами, **важно воспроизвести вид кабинетов**. Автоматы: Морской бой, Городки, Сафари, Скачки, Магистраль (мультиплеер на двоих). Пятнашка-монетка как валюта.
- Поискать эмуляторы/реконструкции (музей советских игровых автоматов делал онлайн-версии). Большинство автоматов — на дискретной логике, без ПЗУ: скорее воспроизводить поведение, чем эмулировать. Для «Электроники» и Brick Game (волна 5) — тоже посмотреть эмуляторы (MAME-драйверы), если потянет браузер.
- Как и ИМ — «как оригинал» → не публиковать как Artifact.

## Волна 14 — Шпион, Лото, генератор ГОПС
- **Шпион** (по мотивам Spyfall): категории — локации, персонажи, фильмы, книги, компьютерные игры, музыкальные группы и исполнители, знаменитости, исторические события. Настройка «только РФ и СССР / весь мир», выбор категорий. По ~300 самых известных реалий в каждой категории × 2 охвата — списки собрать заранее в данные игры (JSON), «генерация» = случайный выбор из них (+ роли для локаций). Боты: задают вопросы по шаблонам, шпион угадывает по словарю признаков.
- **Лото** (бочонки, карточки, «барабанные палочки» и прочие присказки) + вариант **«Вокруг света»** — весь комплект по ссылке в `materials/README.md`.
- **ГОПС** (волна 6): к 10 исходным картам добавить процедурный генератор уровней.
