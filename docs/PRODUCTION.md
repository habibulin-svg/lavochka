# Производство крупных игр: локальные модели, вселенная, дорожная карта

_Составлено 2026-10-31 по ресерчу агентов (данные о моделях на октябрь 2026). Цифры VRAM и скоростей во многом из вторичных источников. Перед загрузкой модели сверять карточку на Hugging Face._

## 0. Как будем работать

| Кто | Что делает |
|---|---|
| Claude (облако) | архитектура, движок, сеть, сложный код; задания на генерацию (`studio/jobs/…`); мелкие задачи по коду для локальной LLM; ревью и сборка готового контента в игру |
| Пользователь | творческие решения (сюжет, названия, персонажи); запуск заданий на машине с GPU; отбор лучших вариантов |
| Локальные модели | массовый контент: картинки, спрайты, текстуры, 3D, музыка, звуки, озвучка, тексты событий; мелкий код по готовой спецификации |

**Главное правило по лицензиям.** Игры платные («Лавочка+», косметика, возможно Steam), поэтому используем только веса с лицензиями MIT, Apache-2.0 или BSD. Лицензии с порогом выручки (Stability Community < $1M, LTX-2 < $10M) допустимы, но каждую такую модель записываем. Веса CC BY-NC, «research only», FLUX dev и Coqui CPML **в продакшн не идут**: их можно только пробовать, но не выпускать сделанное ими.

## 1. Раскладка по железу

VRAM двух карт для диффузии **не складывается**: одна задача идёт на одной карте. LLM в llama.cpp делится по двум картам.

Два режима, переключаются скриптом `studio/mode.ps1` (будет написан):

| Режим | RTX 4070 12 ГБ (CUDA 0) | RTX 3070 8 ГБ (CUDA 1) | RAM |
|---|---|---|---|
| **Контент** (основной) | ComfyUI-A :8188: картинки, видео, 3D, апскейл | ComfyUI-B :8189 или аудио-сервер: ACE-Step turbo, TTS, SFX, фон, апскейл. Параллельно маленькая VLM-проверялка (Qwen3.5-9B Q4, ~6 ГБ) | свободна |
| **Код и тексты** | Qwen3.8-27B Q4_K_M (16,5 ГБ) на обе карты: `-ts 12,8 -sm layer` | ↑ | свободна |
| **Код (альтернатива)** | Qwen3.6-35B-A3B IQ4_XS: слои на GPU, эксперты в RAM (`--n-cpu-moe N`) | свободна под ComfyUI-B | 18–20 ГБ |

Каждый процесс привязывается к своей карте через `CUDA_VISIBLE_DEVICES` (0 или 1) и слушает свой порт. Порядок карт проверить командой `nvidia-smi -L`.

## 4. «Студия» — свой софт под конвейер (`studio/`, Python)

Строить своё приложение с интерфейсом незачем. Нужен тонкий слой скриптов поверх API ComfyUI, llama-server и аудио-сервисов, чтобы задания были воспроизводимыми, а результат приходил в одном формате.

```
studio/
  mode.ps1               переключение режимов «контент» / «код» (запуск и остановка серверов по картам)
  run.py                 python studio/run.py jobs/<игра>/<партия>.yaml
  runners/               comfy.py (две очереди, по карте), llm.py, music.py, tts.py, sfx.py, blender.py
  workflows/             сохранённые workflow ComfyUI в API-формате с плейсхолдерами
  qa.py                  автопроверка VLM: соответствует ли промпту, нет ли артефактов, прозрачен ли фон, читается ли силуэт
  post/                  фон, пиксель-сетка, палитра, нарезка атласов, нормализация громкости, Opus/WebP/glb
  import.py              из отобранного — в lavochka/public/<игра>/… с манифестом
  jobs/<игра>/*.yaml     задания (пишет Claude)
  bible/                 «библия» вселенной: палитра, эталоны стиля, LoRA, голоса персонажей, словарь
```

**Задание** (`jobs/*.yaml`) содержит: какая модель или workflow; сид; набор промптов из шаблона и таблицы (персонаж × поза × ракурс); сколько вариантов на позицию; постобработку; критерии для QA.

**Выход:** `E:\studio\out\<партия>\` и `manifest.json`: файл, промпт, сид, модель, лицензия модели, вердикт QA.

**Ревью:** Claude читает манифест и смотрит отобранное. В игру попадают только одобренные файлы. Лицензия модели остаётся в манифесте, так что для любого ассета видно, чем он сделан.

**Мелкий код для локальной LLM:** `studio/code-tasks/*.md`. Каждая задача самодостаточна: интерфейс, входы и выходы, готовый тест, до ~300 строк, без знания всего проекта. Примеры: таблица характеристик существ из спецификации, генератор имён, парсер карты, тексты 200 событий «Коммерсов». Пользователь запускает OpenCode на задаче, Claude ревьюит дифф и гоняет тесты.

**Где хранить ассеты:** сырые генерации — вне git (`E:\studio`). В репозиторий идут только итоговые сжатые файлы. Репо уже весит 437 МБ (`public/` — 352 МБ). **Решение пользователя 2026-10-31: тяжёлые ассеты крупных игр — в Git LFS.**

Порядок включения перед первым коммитом ассетов первой крупной игры:
1. **Сначала сервер:** на прод-сервере `git-lfs` нет (проверено 2026-10-31). Поставить `apt install git-lfs`, затем `git lfs install` в его клоне. Если LFS-файлы попадут в `main` раньше, автовыкладка подтянет файлы-указатели вместо картинок.
2. Выкладку (`deploy/`) дополнить шагом `git lfs pull` после `git pull`.
3. `.gitattributes` — только для папок ассетов новых игр (`lavochka/public/<игра>/**/*.{png,webp,ktx2,glb,ogg,opus,mp3,mp4,webm}`). Нынешний `public/` в LFS **не переносим**: для этого нужно переписать историю, а force-push запрещён.
4. На новой машине — `git lfs install` до клонирования.
5. Следить за квотой LFS на GitHub (хранение и трафик): каждая выкладка на сервер скачивает файлы. Если упрёмся в квоту — докупить пакет данных или перейти на отдельное хранилище.

## 5. Стратегические решения по вселенной (арт-стиль согласован, остальное — предложение)

**Движок.** Своего движка нет, есть общий каркас сборника плюс библиотеки:
- 2D (Герои, ГОПС, Коммерсы, «Пацан», 2D-этажи) — **PixiJS v8**. Phaser не берём: он навязывает свой цикл и сцену, а это конфликтует с `GameDef`/`GameView`.
- 3D («Заброшка», хоррор-подвал, этаж-побег) — **three.js**: он уже в проекте, опыт с glb, PBR и персонажами есть (3D-холдем).
- Физика: ГОПС — **своя битмап-физика** (маска `Uint8Array`, взрыв вырезает круг, фиксированная точка ради детерминизма). 3D — **Rapier3D** (wasm). Машины — Planck.js или аркадная модель из «За рулём».

**Сеть:**
- Пошаговое (Герои, Коммерсы, ГОПС, карты) — существующие `GameDef`/`Authority`/комнаты: реплей, проверка на сервере, боты вместо выбывших. Для Героев добавить асинхронную игру «по переписке».
- ГОПС во время хода — lockstep ввода активного игрока; итог хода сверяется по хешу маски.
- Экшен (шутер, GTA, этаж-побег) — сначала одиночная игра. Сеть позже, через авторитетный сервер с предсказанием на клиенте. Сейчас в `realtime` его нет, это отдельная подсистема.

**Слой вселенной** (`src/universe/` + `server/accounts`, PostgreSQL):
- общий аккаунт;
- мягкая валюта «семки» в виде неизменяемого журнала;
- общий каталог предметов и инвентарь: кепка носится во всех играх, у каждой игры свои слоты;
- опыт и уровень «авторитет на районе»: общий плюс по каждой игре;
- достижения с соответствием Steam и Game Center;
- начисления только на сервере, по проверенному реплею.

Без лутбоксов и без продажи силы. Право `cosmetics` в `core/rights.ts` уже объявлено и пока пустое.

**Обёртки.** Steam — Electron + steamworks.js. Мобильные — Capacitor со встроенными покупками сторов (Robokassa внутри приложений запрещена). Для РФ дополнительно RuStore и VK Play.

**Арт-стиль — решение пользователя 2026-10-31: «3D → спрайты».**
- Персонажи, существа, юниты, машины — **low-poly 3D → пререндер в спрайты** с toon-шейдингом, контуром и общей палитрой. Так делались сами Heroes 3, Doom, GTA 2 и Worms. Диффузия не держит одного персонажа между кадрами анимации, а Blender держит.
- Фоны, экраны замков, портреты, иллюстрации, вкладыши — **диффузия плюс своя LoRA стиля** вселенной.
- Единая «библия» в `studio/bible/`: палитра 90-х, эталонные кадры, голоса персонажей.

## 6. Дорожная карта: что проще (анализ агента, 2026-10-31)

Человеко-недели — для связки «Claude пишет код, локальные модели делают контент».

| # | Игра | Код | Контент | Техриск | Юрриск | MVP / полная, нед. |
|---|---|---|---|---|---|---|
| 1 | **Дартс ножичками** (бэклог) | S | S: ножи, мишени, ~20 звуков | низкий | нет | 1 / 2 |
| 2 | **Вкладыши** (бэклог) | S–M | M: 100–300 вкладышей, 10–20 треков, разметка ритма | средний: задержка звука на телефонах | высокий, если копировать Turbo/Love is — только свои сюжеты | 3 / 6 |
| 3 | **Коммерсы** | M–L | S–M: 50–100 иллюстраций, 200+ событий | низкий (баланс) | низкий | 6 / 12 |
| 4 | **ГОПС** (Worms) | M | M: риг гопника × 30 анимаций, 20–25 оружий, 8–10 ландшафтов, 300+ фраз | средний: разрушаемый битмап, детерминизм | средний: без узнаваемого оружия Worms | 6 / 12 |
| 5 | **Заброшка** (бумер-шутер) | L | L: 10–15 уровней, 12–20 врагов × 8 ракурсов | высокий: производительность, мобильное управление, сеть | низкий | 10 / 20 |
| 6 | **Пацан к успеху шёл** (GTA 1/2) | L–XL | L: 300–500 тайлов, 25–40 машин | высокий: трафик, пешеходы, стриминг карты | средний: марки машин — вымышленные «под ВАЗ» | 12 / 26 |
| 7 | **Девятиэтажка** | XL (8–10 мини-игр) | XL, разнородный | по этажам: побег-«Fall Guys» высокий, остальное низкое | средний | 4 на этаж / 40+ |
| 8 | **Герои кастета и семок** (Heroes 3) | XL | XL: 8 фракций × 14 существ × 6–8 анимаций, экраны городов, ~100 портретов | высокий: ИИ на карте приключений, баланс | средний: только механики и формулы, без имён и таблиц 1:1; код VCMI (GPL) не брать | 14 (2 фракции) / 50–70 |

**Рекомендация, с чего начать:**
1. **Дартс ножичками** — 1–2 недели. Обкатывает весь конвейер: модель или спрайт → постобработка → игра → звук → косметика (скины ножей) → первый кирпич слоя вселенной (кошелёк и инвентарь).
2. **ГОПС** — первая крупная. Пошаговая сеть почти ложится на наши комнаты, контента умеренно, но он покрывает все типы (риг персонажа и анимации, оружие, ландшафты, озвучка, музыка). Кепки и скины — естественная косметика на всю вселенную.
3. Дальше — «Коммерсы» (технически проще ГОПС, но мало проверяет конвейер), затем «Герои». Если хочется Героев раньше, первым шагом прототипируем бой на гексах с двумя фракциями (4–6 недель, годится как отдельный PvP-режим).

«Девятиэтажка» собирается по этажам и много берёт из сборника: карты с ханыгами — готовые карточные движки, Светка — ИИ-собеседники. Её можно растить параллельно, по этажу между большими играми.

## 7. Монетизация (неагрессивная)

| Игра | Точки |
|---|---|
| Дартс | скины ножей, мишени, след броска |
| Вкладыши | серии-коллекции (часть в «Лавочке+»), альбомы, рамки; пачки за деньги не продаём |
| Коммерсы | вид ларька и офиса, «тачка у входа», кампании-DLC, сезонный рейтинг |
