# Гопник — библия облика (ГОПС и вся вселенная)

Решения пользователя 2026-10-31:
- **Пропорции — чиби:** рост ≈ 2,5 головы, короткие ноги, сутулится, руки в карманах.
- **Кепка шире плеч**, натянута на глаза. Это главный узнаваемый элемент силуэта.
- **Кепки по образцам пользователя** (фото в чате 2026-10-31):
  1. плоская кепка-«уточка» (flat ivy cap) — чёрно-белая крупная ёлочка, низкая, тулья скошена вперёд, жёсткий короткий козырёк пришит к тулье;
  2. та же «уточка» — серая мелкая ёлочка;
  3. восьмиклинка (newsboy) — тёмно-серая шерсть в мелкую крапинку, пуговица на макушке, клинья сходятся к пуговице, мягкий объём.
  Бейсболки, вязаные шапки — не наш силуэт (разве что редкая косметика).
- Треники с лампасами без логотипов, стоптанные кроссовки, ёжик. **Во рту ничего — шелуха семечек лишняя** (решение пользователя).
- Тон — смешно и мило, не угрожающе.
- **Стиль — «a-toon3d»** (выбор пользователя 2026-10-31 по листу партии 1): стилизованный 3D-рендер, toon-тени, чистый чёрный контур, плоские цвета, мягкий студийный свет. Образцы — `a-toon3d-*` из `G:/temp/studio/out/gops/01-concepts/`.

- **Форма (правки пользователя к первой модели):** козырёк короткий (форма кепки — норм), кепка крупнее, силуэт гопника — сутулый, плечи покатые, прищур, ухмылка. Промпт — `jobs/gops/02b-model-ref.yaml`.
- **Базовая 3D-модель — q333** (выбор пользователя 2026-10-31): эталон `threequarter-apose-333` из партии 02b → TripoSG. Хранится в `G:/ai/out/studio/gops/gopnik-base.glb` (+ `-ref.png`, `-preview.png`); в репозиторий — после включения Git LFS.
- TripoSG по виду спереди «досочиняет» длинный козырёк; спасает эталон в ¾ (виден козырёк).

Промпт-основа — `studio/jobs/gops/01-concepts.yaml`, поле `style`.

## Бригады и расцветки

Решение пользователя 2026-10-31: бригады — районы, одеты в классические спортивные костюмы 90-х по образцам (фото в чате). **Логотипы Adidas убраны, расцветки — взяты.** «Три полоски» — товарный знак, поэтому лампасы по умолчанию в две полоски.

Шесть бригад (`studio/blender/liveries.py`): Затулинка, Расточка, Затон, Первомайка, Чемской, **Ленинский** (не Кировский — решение пользователя). Какой район в какой расцветке — пока моё распределение, пользователь может поменять.

Сборка: `blender -b -P studio/blender/gopnik_build.py -- <меш.glb> <выход.blend> <бригада>` — слоты (кепка, голова, куртка, штаны, обувь) отдельными объектами, глаза — овалы по разметке BODY.
