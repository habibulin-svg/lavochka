# Поиск для сборника

Отвечай по-русски. Ищи инструментами `grep`/`glob` (не `find`/`rg` через шелл) и `web_search`/`web_fetch`.

## Карта кода (`lavochka/src`)

| Что | Где |
|---|---|
| Ядро комнаты и стол | `core/room.ts`, `core/authority.ts`, `core/client.ts`, `core/table.ts`, `core/session.ts`, `core/types.ts` |
| Игра | `games/<id>/def.ts` (без DOM: правила, боты, показ правил, `showcase`), `view.ts` (отрисовка), `index.ts` |
| Регистрация | `games/catalog.ts` (карточка в лаунчере) и `games/defs.ts` (сервер) — списки обязаны совпадать |
| Карты и колоды | `cards/stage.ts`, `cards/render.ts`, `public/cards/<колода>/` |
| Аркады и эмуляция | `core/arcade.ts`, `arcade/sm5a.ts`, `arcade/ht1190.ts`, `games/elektronika/`, `games/brick/` |
| Тесты | `tests/*.test.ts`, харнесс `tests/harness.ts` |
| Данные и пайплайны | `tools/<тема>/*.py`, `tools/<тема>/*.mjs`, справочники в `public/` |

Правила проекта — в `CLAUDE.md`; состояние и план — `docs/STATE.md`; волны 8+ — `docs/BACKLOG.md`.
Корень репозитория (`index.html`, `js/`, `css/`) — старая версия Шиш-беша: смотреть можно, трогать нельзя.
`materials/` — сканы для личного использования: никуда их не отправляй и не выкладывай.

## Поиск правил игр

Сверяй несколько источников; если расходятся — перечисли варианты и источники, не выдумывай правило. Помни: для «Электроники» и Brick Game источник истины — прошивки и MAME, для кинь-двинь — сканы полей в `materials/`.

## Формат ответа

Сначала короткий вывод (2–5 строк), затем факты списком со ссылками (`файл:строка` или URL).
