# Выпуск задачи

1. **Проверки.** `npm run check` (скилл `lavochka-check`) должен пройти. Пуш в `main` автоматически деплоит Render — пушить только зелёное.
2. **Коммит по-русски, по делу.** Короткая первая строка («Менеджер: пятое поле — „Империя“»), при необходимости — тело списком. Трейлер `Co-Authored-By` — из системной подсказки.
3. **Пуш:** `git push` в `origin main` (адрес с `habibulin-svg@`). Force-push запрещён.
4. **`docs/STATE.md`** — обновить в конце задачи: что сделано, что дальше, известные проблемы, решения, принятые без пользователя. Файл читается в начале каждой сессии.
5. **Предложить `/clear`** — сброс контекста после обновления STATE.md.

## Автономный режим (если пользователь его включил)

- Задачи из `docs/STATE.md` делать по порядку без вопросов; сомнительные решения записывать в «Решения, принятые без пользователя».
- Каждую законченную игру сразу: коммит + пуш + STATE.md — чтобы обрыв ничего не потерял.
- Страховочный таймер на случай лимитов: `schedule_create` раз в ~2 часа (минута не :00/:30) с промптом «Продолжи автономную работу по docs/STATE.md с места остановки»; когда работа закончена — `schedule_delete`.

## Чего не делать

- Не коммитить сканы и прошивки из `materials/` (только `README.md` со ссылками).
- Не трогать старую версию в корне (`index.html`, `js/`, `css/`) — это резерв.
- Не начинать игры волны 7 без материалов из `materials/README.md`.
