# Проверки сборника

Все команды — из `D:\Claude\Shish\lavochka`. Node лежит в `C:\Program Files\nodejs`, в PowerShell он не в PATH:

```powershell
$env:PATH = 'C:\Program Files\nodejs;' + $env:PATH
npm run check
```

| Команда | Что делает |
|---|---|
| `npm run check` | `tsc --noEmit` + все тесты — **обязательно перед коммитом** |
| `npx vitest run tests/<файл>` | один файл тестов |
| `npx vitest run -t "<имя>"` | тесты по имени |
| `$env:SIM_GAMES=40; npx vitest run tests/games.test.ts` | длинный прогон ботов |
| `npm run build` | `dist/` (сайт) + `dist-server/` (сервер) |

Быстрая проверка только типов без записи (ничего не меняет в дереве):

```powershell
& "C:\Program Files\nodejs\node.exe" node_modules\typescript\bin\tsc --noEmit
```

## Как докладывать

Первой строкой — «ВСЁ ЗЕЛЁНОЕ» или «ЕСТЬ ПАДЕНИЯ (N)». По каждому падению: тест → ошибка (коротко, без простыней лога) → `файл:строка` → вероятная причина. В конце — время прогона.

Если упал прогон ботов — укажи игру, число игроков, пресет и шаг. Чинить не в этом скилле: сначала доклад, потом правка кода.

Новая игра покрывается тестами автоматически, если зарегистрирована в `src/games/defs.ts` (тест сверяет списки `catalog.ts` и `defs.ts`).
